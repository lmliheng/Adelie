仓库：`lmliheng/Adelie`（待建）
定稿日期：2026-10-04

---

## 一、名字

**Adelie = 阿德利企鹅**，企鹅目里最容易被记住的一种：全黑的后背和头、白肚子，以及**眼睛周围那圈白环**——这是它独一无二的标记，也是这个图标唯一的"签名"。

选它的三条理由：

1. **和 PenguinHarness 是一家人，但不是同一只。** PenguinHarness 是缰绳（harness），Adelie 是坐在缰绳里那只企鹅：同一套企鹅视觉、同一个蓝，但它是一只具体、有名字的企鹅，可以自己成为一个产品。
2. **能当命令名。** 6 个字母、无连字符、无重音（法语里的 `Adélie` 重音不进入标识符），`adelie` 一次就能敲对，作为 npm 包名和 CLI 名都成立。
3. **占用干净**（2026-10-04 实测）：npm `adelie` 与 `adelie-core/-cli/-runtime/-tools/-providers/-web/-desktop` 全部 404（可用）；GitHub `lmliheng/adelie` 404（可用）。`adelie.dev / .ai / .app` 已被第三方注册——其中 `adelie.ai` 只是一个停放页，不是同类产品——所以域名这一项要另想办法（`.sh` 当时可用），不影响 npm 与 GitHub。

**一并考虑过的备选**（附实测结果，以备改名）：

| 备选 | 说明 | 占用 |
| --- | --- | --- |
| Korora | 小蓝企鹅的毛利语名，最短的企鹅名之一 | npm / GitHub 均可用 |
| Rockhopper | 跳岩企鹅，头像辨识度高（黄眉） | npm 已占用 |
| Krill | 磷虾，企鹅的食物；短、好念，但不像"一只企鹅" | npm 已占用 |
| Gentoo | 巴布亚企鹅 | 与 Linux 发行版同名，会让搜索结果彻底失焦 |

## 二、图标

### 构成

白底圆角方（PenguinHarness 用来放企鹅的那块板）→ 一道蓝色轨道 → 站在轨道里的阿德利企鹅：深色身子与头、白肚子、蓝喙，**两只眼睛外面各一圈白环**。

- **板**：1024×1024，圆角 246px —— 和 PenguinHarness 的 954×954 / 圆角 230 是同一个比例（24%），所以两个图标并排时是同一族的形状语言。
- **轨道**：圆心 (512,530)、半径 300、线宽 30 的整圆，画在企鹅底下；企鹅站在轨道里，只露出左右两段弧 —— 这正是 PenguinHarness 那只企鹅身后的蓝色扫线，换成了"绕在智能体外面的一圈"。
- **企鹅**：保龄球瓶式剪影，x∈[318,706]、y∈[225,840]，占画面 60%，四周留白足够，任何尺寸都不会贴边。
- **眼环**：外径 24px 白环，圆心 (448,356) 与 (576,356)。这是物种特征，也是整个图标里最小仍然可辨的元素。
- **喙**：蓝色水滴，位于两眼之间偏下。

### 配色（全部取自 PenguinHarness 的标志）

| 用途 | 值 |
| --- | --- |
| 底板 | `#fefefe` |
| 身体渐变 | `#1a2a49` → `#0e1c37` → `#070f1e` |
| 轨道 / 喙渐变 | `#0b2963` → `#054ac8` → `#015dfc`（`#015dfc` 是 PenguinHarness 的品牌蓝） |

两个颜色家族、零种新色：深蓝是身体，品牌蓝是"动作"（轨道、喙），白是留白与眼环。

### 小尺寸表现（见 `preview.png`）

256 / 128 / 64px：企鹅、眼环、喙都清楚。
32px：眼环收成两个白点，白肚子仍在 —— 仍然是一只企鹅。
16px：只剩一个深色剪影加白肚子，作为托盘 / 任务栏尺寸可用。

`adelie-glyph.svg` 是单色版本（肚子、喙、眼环用 mask 挖空），给导航栏、终端标题和 favicon 用。注意：`currentColor` 只在**内联**使用（`<svg>` 直接写进文档）时才继承文字颜色；当 `<img src="adelie-glyph.svg">` 引用时它会渲染成黑色。

## 三、文件

| 文件 | 内容 |
| --- | --- |
| `brand/adelie-icon.svg` | 主标志（含底板），改图标只改这一个文件 |
| `brand/adelie-glyph.svg` | 单色字形，继承 `currentColor` |
| `brand/render-icons.mjs` | 由主标志生成全部位图 |
| `brand/icons/icon.png` | 1024 主图（electron-builder 由此出 `.ico` / `.icns`） |
| `brand/icons/{512,256,128}x*.png` | freedesktop 尺寸组 |
| `brand/icons/icon-{64,48,32,16}.png` | 小尺寸自查组 |
| `brand/icons/adelie.ico` | Windows 图标，内含 16/32/48/64/128/256 六帧 |
| `brand/preview.png` | 白 / 灰 / 黑三种底上的自查图 |

重新生成全部位图：

```bash
node brand/render-icons.mjs     # 需要 playwright + chromium，见脚本头部注释
```

## 四、使用规则

- 最小尺寸：托盘 / favicon 用 16px 的 `adelie-glyph.svg`；应用图标不小于 32px。
- 四周留白不小于图画宽度的 12%（主标志已经留好，不要再裁切）。
- 不换色、不加描边、不加阴影、不旋转；深色界面用主标志（白板自带对比），不要给白板改色。
- 圆角由 SVG 自带（透明角落），宿主不要再套一层圆角，否则会出现双重圆角。
