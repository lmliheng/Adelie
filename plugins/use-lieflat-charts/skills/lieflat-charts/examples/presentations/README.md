# Presentation examples

- `presentation-studies-v3.zh.html`：中文演示版式与翻页交互示例。
- `presentation-studies-v3.en.html`：英文演示版式与翻页交互示例。
- `lenny-2026-survey.zh.html`：中文长文案实验，展示同一套版式如何承载调研叙事；其中部分图形仍保留独立示例数据，只能作为版式研究。

这两份文件主要展示页面编排、导航、打印和图表容器的组合方式。文件中保留的数字是模板示例，不代表同一份真实数据集。生成实际演示时，请按 `catalog.md` 为每页选择图型，并替换标题、数据、来源和无障碍描述。
