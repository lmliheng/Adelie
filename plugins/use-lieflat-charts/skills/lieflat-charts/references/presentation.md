# 演示模式实现参考

## 交付边界

演示模式交付为 HTML 或 PDF 格式的 PPT。HTML 版本将页面样式、数据和页面脚本内联；外部字体和图表依赖必须在交付说明中列出。PDF 可由浏览器打印生成，但 HTML/PDF 都不应称为原生可编辑 PowerPoint 文件。只有用户确认需要 `.pptx` 且接受转换流程时，才另行生成可编辑幻灯片。

## 画布与字体

- 设计画布固定为 `1600 × 900`，16:9 等比缩放，不拉伸或裁切。
- 建议内容区左右各 72px，上 64px，下 72px。来源和页码使用单独页脚区。
- 默认 Mono 页面：纸灰 `#F0EFEB`，炭黑 `#1C1C1A`，不加全局卡片、阴影或渐变。
- 中文标题使用 `Noto Serif SC` / `Source Han Serif SC` / `Songti SC` 回退；正文、图例和脚注使用 `Noto Sans SC` / `Source Han Sans SC`；数字使用 Inter。
- 页面标题建议 56–96px，正文 22–28px，图例和坐标 20–24px，来源与页码 16–18px。最终按 1280×720 和投影距离复核。

## 导航与生命周期

前后方向键、PageUp/PageDown、Home/End、可见页码和 `?slide=N` 定位必须可用。焦点位于输入框或图表交互组件时，不抢占键盘事件。图表在页面首次激活时播放，返回页面默认保留完成状态；`prefers-reduced-motion` 直接显示静态终态。

打印时一张幻灯片对应一页，所有页面都要初始化，控件隐藏，来源和页码保留。不要只依靠用户先翻完所有页面或只在异步 `beforeprint` 中初始化图表。

## 数据契约

每页标题、正文、大数字、图例、悬停提示和无障碍描述必须指向同一口径。保留来源、时间、单位、样本和计算方式。数据不足以支撑图形时使用文字页、删页或请求数据，不用装饰性图形填空。

## 实施顺序

1. 按已锁定的全局色系选起始模板：Mono 用 `templates/presentations/presentation.zh.html` 或 `.en.html`；porcelain / palm / wire 彩色预设用对应的 `complete-porcelain` / `complete-palm` / `complete-wire`（各 19 页、中英双版、带 pop / fade / draw 入场动效）。不要直接修改仓库模板。
2. 写页级记录：页码、主要结论、数据集或来源、图型编号、版式编号和待检查项。
3. 在 `catalog.md` 审计图型并锁定 gallery 代码，再将图表放进 P04–P08 的槽位。
4. 替换所有示例文案、数字、来源和 aria-label。
5. 做 1600×900、1280×720、手机横屏和浏览器打印验收。
