# 新对话页的版本行会写出最新发布版

- **Date:** 2026-10-21
- **Type:** feature
- **Scope:** `web`, `docs`
- **Breaking:** 否

[English](2026-10-21-version-line-latest.md)

新对话页品牌下的版本行此前只写正在运行的版本（`v0.5.1 · 最近更新日期 10月17日`），有新版本时旁边只多一个上标「有新版本可用」，而那个新版号藏在它的悬停提示里。于是落后两个版本的安装看不出自己落后了 —— 这一行正是读者确认版本的地方。现在检查到更新的发布版时，这一行直接写出**最新版本 v0.5.2**（`v0.5.1 · 最近更新日期 10月17日 · 最新版本 v0.5.2`）；已经是最新就不重复写。

## 细节

- 版本号来自应用每次加载都会做的那次更新检查（服务端缓存一小时，也可以整个关掉；关掉时这一行保持原样）。
- 只在「最新版比正在运行的新」时追加：已经是最新的构建，前半句写的那个版本就是最新版，再写一遍没有信息量。
- 检查失败、响应里没有版本号、或者更新检查被关掉，这一行都与以前完全一样。
- 上标徽章（进入更新弹窗的按钮）没有改动：它说的是更新的状态，版本号现在由这一行来说。
- 文档（中英）「查看当前版本」一节补上了这半句。

## 兼容性

- 只是 Web App 里的一行：没有接口、传输格式或依赖变化。
