# 频道保留你还没发出的消息

- **Date:** 2026-10-14
- **Type:** fix
- **Scope:** `web`

[English](2026-10-14-channel-draft.md)

移植自上游 PenguinHarness（#810，提交 `7ecb60e1`）。

在频道输入框里写了还没发出的文字，过去只活在当前视图里：打开另一个频道、某个工位、任何别的页面——或刷新——都会把它丢掉。现在它按用户、项目、组织与频道保存在浏览器里（`penguin.channelDraft.…`），与对话里未发送的输入同一口径：回到该频道，文字还在原处；别的频道不会继承它；发出消息（或清空输入框）才会结束它。磁盘与服务端什么都不变，新键与对话草稿并列归为 install 作用域。
