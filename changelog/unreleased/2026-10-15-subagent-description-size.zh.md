# 智能体面板：子智能体的描述比名称小一号

- **Date:** 2026-10-15
- **Type:** fix
- **Scope:** `web`

[English](2026-10-15-subagent-description-size.md)

移植自上游 PenguinHarness（#1096，提交 `6e54f6bc`）。

智能体面板的调用关系图里，子节点的第二行是派生它的 `run_subagent` 调用所带的描述，此前与上方的
Agent 名用同一档字号 —— 中文描述看上去和名称一样大、甚至更大，节点上「先是谁、再做什么」的层次
就没了。现在名称改用正文字号，描述仍用小号字排在下方，三套主题都是如此。

关系图的节点框、间距与连线也随之跟随「字号」设置：画布按 rem 而不是固定像素排布，节点框因此跟着
它那两行字一起长大，而不是把字挤在里面。此前白领主题在「特大」档会把描述的下沿截掉。同一字号下，
较长的 Agent 名会稍早被截断；节点的 tooltip 仍显示完整的名称与描述。
