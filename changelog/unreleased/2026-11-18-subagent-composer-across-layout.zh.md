# 换布局不再丢掉子 Agent 面板里没发出的字与那几句原因

- **Date:** 2026-11-18
- **Type:** fix
- **Scope:** `web`

[English](2026-11-18-subagent-composer-across-layout.md)

智能体面板是一块停靠面板。窗口跨过断点时（桌面右侧栏 ↔ 窄屏合并面），这块面板会从一侧的挂载点挪到另一侧：
原来那份被卸载，另一侧新起一份，于是**输入框自己状态里的一切都跟着没了**。上一轮的真浏览器探针量过 —— 在子
Agent 的输入框里打到一半的字、以及刚说明完「这次停止没成功」的那句话，跨一次断点就都不见了，再跨回来也不会回
来，而子会话自始至终还在跑。

现在跨布局之后，那三样东西都还在，因为它们在屏幕上仍然成立：

- 你打到一半的那句话（子会话的草稿，和主输入卡一样按会话缓存，刷新也找得回来）；
- **停止**没送到服务器的那句原因（它跟着这次运行走 —— 子会话回到空闲才收走，轮不到一次缩放，更轮不到计时器）；
- 消息没送到子会话的那句原因（草稿和同一颗**发送**按钮就是重试）。顺手把这一格的另外两处也一起留住：思考等级
  没钉住的原因，以及已经钉上去的那个等级（否则选择器会退回子 Agent 只是「继承」到的那个值）。

## 细节

- `packages/web/src/features/chat/subagent-composer-keep.ts`（新）：一张按**子会话**记的模块级记录
  （`draft` / `send` / `stop` / `level` / `pinnedLevel`），两个函数读写。模块状态而不是存储：这几句话说的都是
  还活着的这一按，随标签页一起消失；记录为空就整条删掉，逛过多少个子会话也只留有话可说的那几个。`draft` 这
  一格是必要的：会话草稿缓存有 300 ms 去抖、在卸载时才补写，而补写发生在替换上来的那份**已经读过缓存之后**
  （React 先渲染新子树、再清理旧的），去抖窗口内的那几下按键照样会丢 —— 这一格改在每次编辑时立刻写。
- `packages/web/src/features/chat/subagents-view.tsx`：`SubagentComposer` 的四处局部状态收成一份记录，所有
  写入走同一个 `remember()`（先写存储、再落状态，不等 effect —— 否则又落回「新挂载读的时候还没写进去」的老
  问题）；输入框接上 `useSessionDraft(childSessionId)` 的 `initialText` / `onTextChange` / `initialSkills` /
  `onSkillsChange`，`initialText` 先读记录、再退回缓存；发送或转述成功后草稿缓存与记录里的字一起清掉（发送成
  功的那次清空不会回调，不主动清就会在下次重挂载里复活）。

## 兼容性

只动前端状态与其缓存，接口、线上格式与已存数据都没变。子会话的草稿与主输入卡一样按「用户 × 会话」存
localStorage，之后把子会话当完整会话打开时看到的是同一份草稿。
