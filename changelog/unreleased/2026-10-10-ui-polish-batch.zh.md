# 权限菜单加图标、去掉思考等级脚注，轨迹面板与文件编辑器不再超出宽度

- **Date:** 2026-10-10
- **Type:** fix
- **Scope:** `web`, `ui`

[English](2026-10-10-ui-polish-batch.md)

移植自上游 PenguinHarness（#1007，提交 `2604c5d2`），有一处未取：把 UI 包的折叠内容区限制在折叠区自身宽度内的那处 —— 本树没有 `Fold` 组件。

Web App 的四处修整：输入框权限菜单的每一行在名称前加上所对应等级的盾牌图标；会话中的思考等级菜单去掉了脚注；轨迹面板中的轮次与全局统计不再在右侧被截断；对文件按下「编辑」不再重新折行。

## 细节

- 输入框权限菜单的每一行（各预设；沙盒开关关闭时为各审批模式）在名称前显示选中该行后权限按钮将呈现的盾牌图标，色调与按钮一致：完全访问与部分权限为琥珀色（以图标形状区分），只读为绿色，关闭为弱化色。不可选的行，图标随整行一同变淡。管理员可见的「更多…」一行加上齿轮图标，使其名称与上方各行对齐；菜单的最小宽度约增加了一个图标的宽度，最长的内置行在带有「仅管理员」等备注时仍能完整显示名称。
- 会话输入框的思考等级菜单底部不再显示「立即生效。更换思考等级会使模型缓存失效，建议先压缩上下文。」对话中途更换等级时仍会弹出确认框，说明切换的代价并提供先压缩的选项。该文案已从两份词典中删除。
- 轨迹面板的全局统计只在所在卡片宽到足以完整显示每组的标签与数值时才把三组并排，宽度按卡片本身判断（容器查询），不再按视口判断。此前在对话旁的停靠栏里，三栏并排会把大部分数值截断；卡片不够宽时，三组改为上下排列。上游让轨迹轮次不再被裁掉的另一个原因 —— 折叠内容区的 `min-w-0` —— 不在本树里：本树没有 `Fold` 组件，展开的轮次不会因它被撑宽。
- 开启自动换行时，文件编辑器的文字层与文本框都取滚动区的宽度。此前一段无法断开的长串（如很长的令牌或 URL）会把两层都撑到自身的长度，按下「编辑」后每一行都按这个宽度重新折行，文字高度随之改变。现在编辑时的折行位置与源码视图完全一致。
