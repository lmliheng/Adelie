# 服务器浏览器删掉了

- **日期:** 2026-11-10
- **类型:** 重构
- **范围:** `server`, `web`, `ui-gallery`, `docs`
- **破坏性变更:** 是 —— **服务器浏览器**页面与全部 `/api/server-browser` 路由都删掉了，`ADELIE_SERVER_BROWSER` / `ADELIE_SERVER_BROWSER_BIN` 也不再被读

[English](2026-11-10-remove-server-browser.md)

**服务器浏览器**这个页面没了 —— 那是服务器自己拉起一个 Chromium、把画面按 MJPEG 传到页面里的一套。它是 0.6.3
加的（[服务器自己跑一个浏览器](2026-11-01-server-browser.zh.md)），而在真正用过它的那台机器上，画面的开销比这个页面
带来的东西更贵。桌面应用自己的内置浏览器一点没动：它的页面就是应用自己窗口里的元素，从来不需要服务器上有一个浏览器。

## 删掉了什么

- 那个页面和侧栏里那一行。`/browser` 现在会像其它没见过的路径一样落到 `/chat`。
- 全部路由：状态读、启动、停止、导航、后退、前进、刷新、改尺寸、输入，以及那条 MJPEG 的 `frames` 流。
- `ADELIE_SERVER_BROWSER` 与 `ADELIE_SERVER_BROWSER_BIN` 两个环境变量，以及前一个变量带来的「已被关闭」状态。
- UI 画廊演示里给这个页面做的替身，以及它的文档页与配置说明条目。

## 那台机器上还剩什么

这个功能填过的浏览器配置留在数据根目录里（`browser-profile/`），里面有登录状态留下的东西。升级不会自己删它 ——
等里面那份数据不再要紧时，手工删掉那个目录即可。

## 兼容性

产品里没有别的地方调过这些路由，所以没有任何调用方需要改。仍然导出了 `ADELIE_SERVER_BROWSER` 或
`ADELIE_SERVER_BROWSER_BIN` 的部署照常启动，这两个名字只是不再有人读。
