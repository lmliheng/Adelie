# 模型库新增智谱官方免费档 GLM-4.7 Flash

- **Date:** 2026-10-07
- **Type:** feature
- **Scope:** `model-catalog`, `docs`

[English](2026-10-07-glm-4-7-flash.md)

内置模型库的直连 Z.AI（GLM）分组新增一条：**GLM-4.7 Flash**（`glm-4.7-flash`），智谱自己的免费档。
2026-10-07 读取自 Z.AI 的价格页（docs.z.ai/guides/overview/pricing，四项均标 `Free`）与智谱开放平台的
免费模型页（docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash）。

## 这条条目

- 上下文窗口 200,000 Token、输出上限 128K，文本进文本出；思考模式、流式输出、Function Calling、
  上下文缓存与 MCP 都支持——两个平台的文档都是这么写的。
- 价格记作真正的 $0，与自建 vLLM 条目、`:free` 网关条目同一处理：成本中心把它的用量按 0 计费，
  模型卡片显示免费徽标，而不是价格缺席所代表的「未计价」。
- 这一条固定了 GLM 客户端、不固定端点。AgentHub 只在路由标记（`client_type` 或 id 本身）含
  `glm-5` 时才把模型交给统一的 GLM 客户端，而这个 id 带的是 `glm-4.7`；不固定就会被 AutoLLMClient
  直接拒收。这个写法与另外两条同样需要的条目一致（`deepseek-flash`、MiniMax M3）。走哪个平台仍由
  `ZAI_BASE_URL` 决定——Z.AI 与智谱开放平台用同一个 id 提供服务。
- 它排在 GLM-5 各行之下是因为更早、不是更小：Z.AI 的发布记录把 GLM-4.7-Flash 记在 2026-01-19，
  GLM-5 记在 2026-02-12，GLM-4.7 记在 2025-12-22。

## 既有 Project

预置条目在创建 Project 时复制进去；模型页的**同步预置**会把这条补进既有 Project。如果某个 Project 已经
自己加过 `glm-4.7-flash`，它的 base URL、密钥与输出上限都保持原样——同步只动目录能作主的那部分事实，
从不覆盖这些。模型页的 Z.AI 分组见 `packages/docs/content/models.{zh,en}.md`，那里已列出该条目并说明了
免费档。
