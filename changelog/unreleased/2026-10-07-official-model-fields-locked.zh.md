# Web：内置模型（官方模型）的接入地址与三档价格在配置对话框里只读

- **Date:** 2026-10-07
- **Type:** feature
- **Scope:** `web`

[English](2026-10-07-official-model-fields-locked.md)

模型配置对话框原先允许覆盖内置模型的「自定义 base URL」和三档价格（缓存命中 / 缓存未命中 /
输出）。这两样都属于内置目录：条目本身就带着接入点和牌价，「同步预置」也会把目录的数字写回
到落后了的行上。而被改写的接入点就是这一行的凭据 —— 之后的每一次请求都发到粘贴进去的那个
地址，界面上却没有任何地方说这一行已经不是目录里的那个模型了。

现在，目录认得的行上这两个字段只读，base URL 字段下面有一行写明原因和正规的出路：「移到自定义
分组」之后这一行就是用户自己的了，两个字段随之可改。锁跟着**当前选中的分组**走 —— 把行移出原来的
分组就解锁，把 id 改成目录里的另一个模型仍然锁着（那已经是另一个模型），改成目录外的 id 则解锁。
同一行上的其它东西照旧可改：API key、上下文窗口、输出上限、快速模式、显示名。

官方行同时豁免「必须填写 base URL」这条校验：字段根本打不进字，要求它只会让这一行永远存不下去，
而它要的那个地址正是目录已经写明的那个。

## Web

- `features/models/models-page.tsx`：对话框新增 `official` 判据（当前这一对 `(provider, modelId)`
  命中内置目录），据此把 base URL 输入框与三个价格输入框置为只读，并在 base URL 字段下方与这几个
  字段的 hover title 里说明原因。
- `lib/strings.ts` / `lib/strings-en.ts`：新增 `models.officialLockedHint`。
