# 切回 Session 时，面板仍停在原来的全屏状态

- **Date:** 2026-10-14
- **Type:** fix
- **Scope:** `web`

[English](2026-10-14-session-dock-fullscreen.md)

移植自上游 PenguinHarness（#1128，提交 `8f747606`）。

切到别的 Session 再切回来，停靠面板总是普通尺寸 —— 因为切换本身把全屏状态清掉了。现在全屏按**停靠布局**
记在内存里：一个 Session 可以让右侧停靠栏全屏，另一个同时让底部停靠栏全屏，草稿发出的第一条消息所创建的
Session 也继承草稿的全屏状态。

跨 Session 共用的面板宽度与底部高度不变。退出全屏、隐藏停靠栏、关掉它的最后一个标签页都会清掉；把某个
不在前台的 Session 的最后一个终端标签剪掉时也一并清掉，免得终端再回到那里时全屏还挂着。刷新页面与跨越窄屏
断点仍从普通尺寸开始，localStorage 的格式一字未改。
