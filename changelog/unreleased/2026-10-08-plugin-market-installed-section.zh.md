# 插件市场：工作 Agent 没有的插件归到「可安装」，不再列进「已安装」

- **Date:** 2026-10-08
- **Type:** fix
- **Scope:** `web`

[English](2026-10-08-plugin-market-installed-section.md)

插件市场页原先把**每一个**插件库插件都列在「已安装的插件」里，不管有没有谁装过。而这一节里的卡片
带的是「当前选中的 Agent」的状态标签 —— 于是同一个界面上，分区标题写着「已安装」，卡片上写着
「未安装」：同一个插件两个说法，其中一个是错的。

现在两个分区就用那个状态来分（`splitPluginRows`），一行只能待在它的标签所说的地方：

- 当前 Agent 装着这个插件（标签是「已安装」或「可更新」）：留在「已安装的插件」里，原来那个
  一键更新照旧；
- 没装：这一行移到「可安装」，读者看到的是它的「未安装」标签和「安装」按钮。在那里装完就回到
  上一节（两个分区本来就是一张表）。

项目自己的模块插件不是「某个 Agent 的状态」，仍旧留在已安装那一节 —— 项目插件表一直摆在那里。
没选中 Agent 时没有任何可比对的东西（卡片此时也不画状态标签），插件库的行保持原位。

状态筛选跟着一起走：插件库的行按它标签上的状态计数（当前 Agent 没有的记作「可安装」），
不再一律记成「已安装」。

## 网页端

- `features/plugins/plugins-page.tsx`：新增 `splitPluginRows`、插件库行上的 `market` 字段、
  由它得出的状态 facet，以及两个分区共用的一张插件卡片。
- `lib/strings.ts`：两个分区标题的说明注释。
