# The Android app's source now lives in this repository

- **Date:** 2026-11-22
- **Type:** process
- **Scope:** `android`, `docs`

[中文](2026-11-22-android-app.zh.md)

The sideloadable Android APK — a bionic Node 24 with the harness and its own web front end packed
inside — used to exist only in the temporary workspace of the machine that built it. Its source now
lives in `android/`. The current beta is 1.0.1.

## What came in

A complete Gradle project (AGP 8.7.3 + AndroidX + Material 3, `app/src/main/{java,res,AndroidManifest.xml}`,
plus the Robolectric screenshot case under `app/src/test/`) and the four scripts that build it:
`build-node-android.sh` cross-compiles Node with the NDK, `patch-zlib-cpufeatures.py` fixes zlib not
finding `cpu-features.h` on arm64, `gen-icons.py` generates the five mipmap densities and the adaptive
foreground from the official icon, and `build-apk.sh` places the compiled node and the harness into
`jniLibs/` and `assets/` before calling Gradle. `publish-3003.sh` / `finish-v2.sh` publish the built
package to a static site and read it back to verify, and `notify.py` reports a long build's outcome.
`README.md` records the build commands, the runtime layout and the known limits (arm64-v8a and x86_64
only, no `node-pty`, the sandbox degrading to direct execution); `screenshots/` and `icons-src/` are
its pictures and icon sources.

## Source only

`libnode.so` in `app/src/main/jniLibs/` and `assets/payload.zip` are generated by `build-apk.sh` at
packaging time, and `build/`, `.gradle/`, `local.properties` and any built APK stay out of the
repository too: the new `android/.gitignore` keeps them out. The whole project with its generated
output is about 1.7 GB; what goes in is a little over 1 MB of source and scripts.

The beta distribution address that was hard-coded in the scripts and the README is now the
environment variable `BASE_URL` (defaulting to the loopback), matching the `SITE_ROOT` / `BASE_URL`
handling `publish-3003.sh` already had — so that machine's address no longer appears in the docs.

## Tests

- What is committed is source; no APK was rebuilt for this. To reproduce, run
  `bash build-apk.sh arm64` as `android/README.md` describes; the Robolectric interface case needs an
  Android SDK and `/opt/gradle-8.9` on the machine.
- The committed files were checked to carry no credentials, no beta distribution address and no
  generated output: a full-tree `grep` found nothing, and `git status` lists only source and scripts.
