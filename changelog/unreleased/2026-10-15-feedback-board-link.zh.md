# 账号菜单多一行「反馈社区」，一键到公开反馈板

- **Date:** 2026-10-15
- **Type:** feat
- **Scope:** `web`

[English](2026-10-15-feedback-board-link.md)

左下角账号菜单多了一行**反馈社区**，点开就是产品的公开反馈板（腾讯兔小巢），在新标签页里打开，
不打断当前页面。在那儿可以发帖，也能看到别人已经报过的问题。

它和旁边那行**用户反馈**是两扇门，所以并排放着而不是合并：原来那行写的是「直接收进这台机器的
反馈队列」，而且只有这台机器配了反馈后端时才出现；公开板块属于产品本身，每个安装都是同一个地址，
因此永远都在。板块那行带一句小字说明「公开」，两行的区别一眼看得出来。

外链按仓库既有做法打开：新标签页 + `noopener,noreferrer`，桌面客户端里则由外壳交给系统浏览器
（和「项目在 GitHub 上」「打开 Releases 页面」同一条路）。
