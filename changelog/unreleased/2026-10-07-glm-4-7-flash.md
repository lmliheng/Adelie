# Model catalog: Zhipu's free GLM-4.7 Flash

- **Date:** 2026-10-07
- **Type:** feature
- **Scope:** `model-catalog`, `docs`

[中文版](2026-10-07-glm-4-7-flash.zh.md)

The built-in catalog gains one row in the direct Z.AI (GLM) group: **GLM-4.7 Flash**
(`glm-4.7-flash`), Zhipu's own free tier. Read 2026-10-07 from Z.AI's price list
(docs.z.ai/guides/overview/pricing), which lists it `Free` on all four of its buckets, and from
智谱开放平台's free-model page (docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash).

## The row

- 200,000-token context window with a 128K output cap, text in and text out, thinking mode,
  streaming, function calling, context caching and MCP — as both platforms document it.
- Priced at a genuine $0, the treatment the self-hosted vLLM rows and the `:free` gateway rows
  already get: the cost center bills its usage at 0 and the model card shows the free badge,
  rather than the "unpriced" mark an absent price means.
- The row pins the GLM client and no endpoint. AgentHub hands a model to its unified GLM client
  only when the routing token — `client_type`, or the id itself — contains `glm-5`, and this id
  carries `glm-4.7`; unrouted, AutoLLMClient rejects it outright. The pin follows the two rows
  that already need one (`deepseek-flash`, MiniMax M3). `ZAI_BASE_URL` still decides which
  platform is billed, since Z.AI and 智谱开放平台 serve the same id.
- It sits below the GLM-5 rows because it is older, not because it is smaller: Z.AI's release
  notes date GLM-4.7-Flash to 2026-01-19 and GLM-5 to 2026-02-12, with GLM-4.7 on 2025-12-22.

## Existing Projects

Presets are copied into a Project when it is created; the models page's **Sync presets** brings
this row into an existing one. A Project that already carries a hand-added `glm-4.7-flash` keeps
its own base URL, key and output cap — a sync touches catalog facts only, and never overwrites
those. The models page's Z.AI group is documented in `packages/docs/content/models.{zh,en}.md`,
which now lists the row and explains the free tier.
