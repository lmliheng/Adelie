# 承载屏幕上没有的信息的悬停提示重新显示

- **Date:** 2026-10-16
- **Type:** fix
- **Scope:** `ui`, `web`

[English](2026-10-16-key-hints-restored.md)

移植自上游 PenguinHarness（#1051，提交 `e5639b32`）。

悬停提示的规则只在元素没有自己的文字、或文字被截断时才弹出提示。于是那些承载屏幕上没有的信息的提示 ——
点击会丢弃什么、快捷键、文件夹名背后的完整路径、控件为何置灰 —— 在带可见文字的控件上不再出现；头像
首字母和当图标用的字母也被算作可见文字，让为它们命名的提示一并失效。规则现在不计这类文字，补充可见
文字的提示经标记后照常显示。

## 细节

- `hintAllowedFor` 不再把 SVG 内与 `aria-hidden` 内的文字算作元素自己的文字，为头像命名的提示因此重新
  显示（会话行的 Agent、收起侧栏的账号、公司页面的员工）。会话行的待审批数与标签的 × 改为 `aria-hidden`
  的标记，待审批数改由隐藏文字命名。
- 带 `data-tooltip-extra` 标记的 `data-tooltip` 在文字完整可见时也显示；`<Tooltip extra>`、标签与
  导航行的 `tooltipExtra`、表单选择器的 `titleExtra` 打同一标记。`Badge` 的 tooltip 与 `BetaBadge`
  的 title 一律带标记；`Breadcrumbs`、`DockTabs`、`Legend`、`FileTree` 与 `ToolCallCard` 在提示多于
  标签时标记。
- 只重复屏幕上已有文字的提示永不标记、也永不显示 —— 这条规则没变。
- 上游那份清单上的位置并非本树都有：插件市场的卡片、查找栏、草稿页的示例文件夹（本树这里放的是用户
  自己的快捷提示）、转录注记与 API 试用面板都不在这次移植里。快捷提示行的填充动作改打了标记，因为它
  承载的是同一类信息。
