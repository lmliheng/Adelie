# 文档的语言标记跟随界面语言

- **Date:** 2026-11-16
- **Type:** fix
- **Scope:** `web`

[English](2026-11-16-html-lang-follows-ui.md)

文档根的 `lang` 属性现在与界面语言一致，英文界面按英文宣告。此前无论屏幕上是英文、中文还是「跟随系统」，
它都写着 `zh-CN`：那是 `index.html` 里的静态字面量，应用内没有任何地方改写它 —— 读屏软件因此宣告错误的
语言，浏览器翻译与断词启发也把每一页当作中文。

## 细节

- 生效语言（`en` 或 `zh`；「跟随系统」先按设备语言解析成两者之一）在与切换活动词典的同一轮渲染里写到
  文档根，所以切换语言、刷新之后、以及系统模式下设备语言变化时，标记都与屏幕上的文字一致。
- `zh` 宣告为 `zh-CN`（简体中文词典），`en` 宣告为不带地区的 `en`。
- 写入经由 `applyDocumentLang(document, locale)`：一个以文档为参数的小导出函数（与
  `applyWorkflowTheme(doc, …)` 同一个形状），node 环境的单测因此无需 DOM 就能覆盖取值口径与写入本身。
- `index.html` 里那个静态的 `zh-CN` 留着当初次渲染之前的默认值：首屏与没有脚本时的浏览器看到的就是它，
  应用起来之后第一次渲染会把它换掉。
