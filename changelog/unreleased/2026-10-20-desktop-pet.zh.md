# 桌面版能养一只桌宠了：通知、新版本和模型余额都落在企鹅身上

- **Date:** 2026-10-20
- **Type:** feature
- **Scope:** `desktop`, `server`, `web`
- **Breaking:** no

[English](2026-10-20-desktop-pet.md)

桌面版多了一个伴随窗口：主窗口所在屏幕的右下角蹲着一只阿德利企鹅，压在其他窗口之上，背景是透明的 ——
它浮在桌面上，而不是待在一个框里。设置 › 外观在托盘图标开关旁边多了一个「显示桌宠」，桌宠自己的面板
里也有一个把它收起来的入口，两者写的是同一份偏好，不会互相矛盾。它**默认关闭** —— 托盘图标是用户已经
打开的那个窗口里的装饰，桌宠则是自己的一扇窗、会盖住别的应用，所以它只在该出现的时候出现。壳把选择记在
用户数据目录的 `pet.json` 里，开着的时候下次启动就把窗口开出来。

桌宠要说的话：一次一句，出现在企鹅上方的气泡里 —— 定时任务触发了（带任务名）、有 N 个工具调用在等批准、
同事的花费接近或超过预算 —— 最近五条留在点开的面板里。面板里还有账号上固定住的分组余额与刷新动作、
客户端更新状态连同那个状态唯一能做的动作（检查 / 下载 / 重启安装），以及最新一条通知。

## 细节

- 桌宠窗口是同一个应用来源的第二个窗口，加载的是 Web 应用自己的一条路由（`/pet`）：没有 preload、
  没有 IPC 桥、也没有单独托管的页面。它无边框、透明、不可缩放、不进任务栏、始终置顶；页面画出企鹅，
  并把窗口其余部分标成可拖动区，所以在企鹅之外的任何地方按住它都能拖动。
- 它显示的一切都走其他页面读的同一套 HTTP 面：用户级事件流回答「没人看着的时候发生了什么」，壳的更新
  快照，以及固定住的模型余额。走的是用户级事件流，所以任何会话里定时任务触发、任何会话里有工具调用在等
  批准、任何员工预算告警，都能传到桌宠这里。
- 开关走的是托盘开关同一条中继：服务端 `GET`/`PUT /api/desktop/pet`，只对壳自己的窗口开放、别处一律
  拒绝，然后一帧 `desktop-pet-command` 经 utilityProcess 通道送到壳，由壳写 `pet.json` 并开关窗口。
  缺少 `showPet`、或者它不是布尔值，在路由处就被拒掉，不会转发给壳。
- 窗口 260×248，贴在主窗口所在显示器工作区的右下角、距边 24px。它不是穿点击的 —— 透明的像素也会吃掉
  落在上面的那一次点击 —— 所以尺寸只留气泡和企鹅一起需要的那点空间。
- 企鹅是 Web 应用里的内联 SVG，固定配色、不依赖外部资源；系统要求减少动效时它就不轻轻摇晃。
- 桌宠页面每分钟重读一次更新快照，只有播报过的状态真的变了才开口：壳把快照推给服务端，所以是这次轮询
  让它变成桌宠能说出口的话。
- `/pet` 是一条普通路由。在浏览器标签里打开，企鹅照样画出来、通知照样到达；两项属于壳的读数会说清
  「只在桌面应用里能读」而不是报错，而没有桌宠窗口可藏的地方就不提供「隐藏桌宠」。
- 桌面壳的冒烟运行现在会报告桌宠窗口的地址与标题，在被要求截图时还会把它一并截下来，名字挨着主窗口那张。

## 兼容性

- 没有改动任何已有的东西：本轮只是多了路由、偏好文件和窗口。`showPet` 默认关闭，所以此前没有桌宠的
  安装升级后依旧没有，直到打开那个开关；桌宠中继新增的壳成员都是可选的，没有它们的壳不需要应答。
