# Adelie v0.6.4 —— 七处「点了没反应」，原因留在发起动作的地方

这一版自 v0.6.3 起在 `main` 上落了 **7 个用户看得见的改动**（其余是每轮的记账与两笔测试稳定性修正）。
数据根、配置格式、包名与既有的请求接口都没有变化，装好的机器升级后不用改任何配置。

七处都是同一件事的收尾：**被拒的操作，原因不再只活在一条六秒的通知里**。这些页面都不做乐观写入——
被拒之后表单、开关、卡片一个字都不变，于是「为什么」是唯一能说明这颗按钮被按过的东西；通知一走，
屏幕上就像什么都没发生。现在每一处都把服务端的原话画在发起动作的那个控件旁边，留到下一次同一种写为止。

## 这一版改了什么

1. **消息渠道扫码连接失败时，原因留在那张卡片上。** QQ 与微信两张扫码卡失败之后的样子本来是一样的：
   二维码撤下来、能再试一次的按钮还在，理由只在一条六秒的通知里。现在扫码起不来或轮询放弃时那句话画在
   扫码按钮下面，微信拒了那组数字时画在配对码输入框下面，由下一次尝试清掉；请求本身没到服务端时念错误码
   自己的本地化句子。本来就连着（`already_bound`）仍走通知——那一次什么都没失败，也没有可重试的。

2. **消息渠道绑定的「测试连接」没通过时，原因留在按钮下面。** 那颗按钮跑的是表单里还没保存的地址与凭据，
   被拒之后表单一个字不变、按钮就是重试，此前读者只能追一条六秒的通知。

3. **模型库弹窗的「检测协议」没认出协议时，原因留在 base URL 字段下面。** 认出来只把协议填进字段，
   没认出来表单一个字都不变，而那句话点名的 API Key 与 base URL 就在同屏——现在它画在字段下面，
   留到表单被编辑、手动选了协议或下一次检测开始；保存时顺带检测没认出来的那条提示仍是通知。

4. **模型库的视觉「检测」没得出结论时，原因留在开关下面。** 接受与拒绝两种答复会把开关挪到读者眼前，
   那一下就是这次按键的交代；「什么也没学到」什么都没写，于是理由成了唯一痕迹。顺带修一处说错了标的
   诊断：这四条失败路此前借的是协议探测那句「无法检测接口协议，请检查 API Key 与 base URL」，
   而读者按的是关于图片的按钮；现在以「视觉检测失败：」带出服务端转来的上游原文。

5. **内置浏览器「设置主页」存不下去时，原因留在地址字段下面。** 弹窗只问一件事——新建标签页与主页
   按钮打开哪个地址——「保存」发出去的正是字段里的那一条，失败之后要改的也正是它。现在那句话画在字段
   下面，字段的任何变化（打字 /「使用当前页面」/「清除」）都清掉它。

6. **组织图「换工位」被拒时，原因留在弹窗里。** 第二笔写入（开一个新的工位会话）失败时，弹窗与字段
   都还留着、重试还是同一颗按钮，理由却只落进通知；现在它画在弹窗体里、工作区字段上面，与被拒的
   「工作区无效：…」分开——被拒的是换工位这件事，不是框里那条路径。

7. **智能体停靠栏里子会话的消息发不出去时，原因留在输入框上方。** 那个输入框有意留着发不出去的那段文字
   （`onSend` 返回 false 就是为这个），失败的原因却只落进通知，通知消失后屏幕上是一个仍装着草稿的框、
   同一颗重试按钮，以及「刚才发生了什么」的空白。现在那句话画在框上方，留到下一次发送或转向，
   在请求发出之前清掉；子会话已被释放时仍念它自己那句。

除此之外有两笔只动测试用例的修正：终端压缩的用例改为等到大帧真的上线再判断，工作流用例的启动步骤
从十秒放宽到三十秒——都是整仓并行、八核占满时才会露头的偶发红，判断条件一条没有放松。

## 兼容

- 请求、响应与磁盘格式都没有变。这一版只有页面上的呈现变化（拒绝的原因画在控件旁边），
  没有新增接口，也没有新增环境变量。
- 新装的机器与升级的机器都不需要改配置。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.4。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.6.3）让浏览器也能跑在服务端那台机器上、画面实时传回网页，输入法打中文也接上了。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
