# Adelie v0.8.4 —— 模型库补上 Gemini 4，桌宠通话界面重做

内置模型库的 Google 分组补上 **Gemini 4** 的四条，顺带修好了模型配置弹窗里那个「锁着却空着」的接入
地址框。核心引擎里，**被中断的那一轮重发时，输入里的图片不再被丢掉**。桌面端这版把**桌宠的实时语音
通话**从一块面板改成气泡对话、挂断与静音换成圆形按钮、桌宠大小可设，**托盘菜单**改成自己画的并多了
「重启」。Web 侧，插件卡片自己打开的弹窗在安装快照落地时不再自己关掉。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.8.4。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**Gemini 4 四条进模型库。** `gemini-4-carbon`、`gemini-4-argon`、`gemini-4-neon`、
`gemini-4-hydrogen` 四条进了内置目录的 Google 分组，窗口都是 1,048,576 Token，都读图。Carbon 与
Argon 是旗舰推理档，Google 在 2026-11-30 之前一律按半价收，12-01 起回到 $4 / $20 / $0.20 每百万
Token 的牌价；Neon（$3 / $15 / $0.15）与 Hydrogen（$1.5 / $7.5 / $0.075）只有一个公布费率。已经在
用的 Project 靠**同步预置**拿到这四条，新的 Project 建好即有。

**模型配置里看得见内置的接入地址。** 内置（目录里的）模型打开配置时，那个 base URL 框一直是锁着的、
旁边写着「接入地址与三档价格由内置目录固定」，可框里是空的 —— 因为它打开的是直连厂商分组，地址本来
由客户端自己带。现在这个框会把内置的接入地址显示出来：例如 Google 分组的
`https://generativelanguage.googleapis.com`、网关分组显示它预置的端点。vLLM 与 Custom 分组不显示，
那里的地址是你自己的。

**被中断的那一轮重发时，图还在。** 发一张图问「这是什么」，还没答完就按了停止（或供应商回了致命
错误），下一条消息原先会让模型回答一张已经不在请求里的图 —— 那一轮的输入被折成一段文字时，图片被
静默丢掉了。现在图片会跟着那一轮的说明一起带上，位置就在说明上方；连续中断两次也不会重复带同一张。

**桌宠通话界面重做。** 实时语音通话从一块面板改成气泡对话：谁说的就气泡跟着谁，每个气泡自己报说话
人；挂断与静音换成两个圆形按钮；对话时的动作重写（说话时的呼吸、接通与结束的过渡）。设置页的「桌宠
形象」下面多了**桌宠大小**（小 / 中 / 大），改完立即生效，不用重开桌宠窗口。

**桌面托盘菜单自己画，多了「重启」。** 系统托盘图标的右键菜单不再用系统默认样式，改成应用自己画的，
多了「重启」，去掉了「新建会话」与「模型」两项（它们都在主窗口里）。

**插件卡片的弹窗不再自己关掉。** 插件卡片上自己打开的确认框（更新、卸载那几个），在安装状态快照
落地、卡片换分区时曾被 React 一起卸掉，正在读它的人会莫名其妙地被合上；现在这类弹窗挂在卡片之外，
快照刷新不再动它。

## 值得一提

- 这一版**没有数据库迁移**，数据根、配置文件格式一个字节没动。
- 桌面端的新特性（桌宠通话界面、桌宠大小、托盘菜单）要**更新桌面应用**才看得到；命令行与 Web 端的
  更新照常。
- Gemini 4 Carbon 与 Argon 的半价是 Google 的限时促销：存的是牌价加折扣率，促销一结束删一个字段
  即可，成本中心按卖家当下收取的价格计费。

## 兼容

- 服务端给桌面宠物的状态多加了一个可选的 `size` 字段：新桌面应用读它，旧桌面应用忽略它，服务端对
  旧壳照常工作。
- 内置浏览器连接协议仍是第 2 版，与 v0.8.3 的桌面应用互相兼容。
- 数据根与配置文件格式没有变化；没有新增或删除页面与环境变量。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.8.3）把桌面应用的内置浏览器按对话分开，标签与 cookie 不再互串；再上一版（v0.8.2）给
Adelie 开了一扇对外的门（外部应用可以拿用户令牌问「这是谁」）。文档在
<https://lmliheng.github.io/Adelie/docs/>。本版全文见
[`docs/releases/RELEASE-v0.8.4.md`](https://github.com/lmliheng/Adelie/blob/main/docs/releases/RELEASE-v0.8.4.md)。
