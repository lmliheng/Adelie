# Adelie v0.5.4 —— 被拒绝的原因继续留在框里，组件库多了一族 GPU 背景

这一版自 v0.5.3 起在 `main` 上落了 **14 笔提交，其中 4 个用户看得见的改动**（其余是每轮的记账与一处测试
工具的修理）。数据根、配置格式、包名与既有 HTTP 接口都没有变化，装好的机器升级后不用改任何配置。

## 这一版改了什么

1. **插件设置里的操作被拒时，卡片留着、原因也在卡片里。** 插件卡片上的操作（部署必须在这台机器上做一次的
   事，比如 Windows 沙盒的「初始化」）执行前要先确认，而那张卡片过去在按下「执行」的那一刻就关掉了。请求
   被拒、或分组自己回答「此卡片上还有任务在运行」的时候，机器一点没变，原因却是一条六秒后自己消失、还浮在
   卡片上方的提示。现在卡片**拿到答复**才关：被拒就把服务端那句话画在句子下面，重试就是同一个按钮。

2. **批量删除对话被拒时，框和勾选都留着，删了一半也说得清。** 批量删除是逐条发出去的（服务端没有批量
   路由），所以它可能只成了一半。过去用的是「一条被拒就丢掉其它行的结果」：列表与服务端已经对不上，而行却
   全还勾着，再看一眼分不清哪些已经没了。现在每条的结果都收下来 —— 删掉的行离开列表与勾选，**被拒的行留着
   勾**（卡片里的条数正好是「重试会动到的那几条」），框留着并画出服务端原话，整批都删掉才关框。

3. **删除 MCP Server 被拒时，同样留着框与原因。** 智能体设置「工具」页的 MCP Server 表里，删除一行是先
   确认再整张表写回去；那张卡片过去在请求返回时就关，不管写没写成功，被拒的原因只剩一条会消失的提示。现在
   写成功之后才关，被拒就把原话画在句子下面，重试还是同一个按钮。

4. **组件库多了一族 GPU 背景。** `@adelie/ui` 现在有会自己漂移的**色彩场**（两色在 oklab 里流动、一层很轻
   的噪点、可选跟着指针的拖尾）与**点阵**（一色一间距的「工程纸」，静止或微闪），建在 MIT 的 `shaders` 上、
   走 WebGPU 画。要紧的不是好看，而是**不会破相**：盒子先问这台设备画不画得了（WebGPU 探针 + 系统的「减少
   动效」设置），画不了就把调用方给的静态替身放进同一个盒子（同色的渐变、或一排 CSS 点），设备中途把画布
   收回去也立刻切回替身。颜色由调用方传（GPU 画布读不到 CSS 变量），画廊新增的「着色器」话题按当前主题的
   色值演示这两块，并显示它此刻画的是画布还是替身。**目前还没有页面在使用它们** —— 先在画廊里可用。

看不见的一处：给工作区包加依赖时，pnpm 会把 `@adelie/ui` 装成 `node_modules` 里的副本，而打包那一步在那里
找不到它的 tsconfig，退回老式 JSX 编译，于是 Web 与画廊的单测整片报 `React is not defined`。这个问题一直埋
着，这版把两份测试配置写明用新版 JSX 运行时，两种装法都验过。用户看不见，但它会让以后每次加依赖都不再翻车。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上 24 个包都到了 0.5.4。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.5.3）把「写入被拒绝的原因」铺到模型库、定时任务、评估中心、插件市场与删除对话，并让桌宠真的
拖得动；再往前（v0.5.2）加了桌宠、结束的定时任务自己移进 `expired/`、MCP Server 可以停用而不必删除。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`changelog/unreleased/`](https://github.com/lmliheng/Adelie/tree/main/changelog/unreleased)。
