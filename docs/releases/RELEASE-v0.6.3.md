# Adelie v0.6.3 —— 网页里也能开浏览器，被拒的原因又少了几处一闪就没

这一版自 v0.6.2 起在 `main` 上落了 **14 个用户看得见的改动**（其余是每轮的记账）。数据根、配置格式、
包名与既有的请求接口都没有变化，装好的机器升级后不用改任何配置。

两件事撑起这一版。一是**浏览器不再只属于桌面窗口**：用网页版、在容器里、或者隔着网络打开 Adelie 时，
过去一个页面都打不开，因为内置浏览器是 Electron 窗口里的一个元素；现在浏览器跑在服务端那台机器上
（服务端自己给它一个虚拟显示器），画面实时传回网页，点击、滚动、打字再传回去，输入法打中文也接上了。
二是**「点了没反应」的收尾又推进一轮**：十二处被拒的操作，原因不再只活在一条六秒的通知里，而是留在
发起动作的那一处——插件卡片、回收站那一行、清理模式的开关、Agent 各分区的启用开关、提示条、保存
确认框、MCP 卡片的「测试连接」、模型库弹窗的「测试连通性」，以及三处设置页读不出来时的空页。

## 这一版改了什么

1. **服务器自己跑一个浏览器，画面实时传到网页里。** 内置浏览器此前是桌面应用窗口里的元素，网页版、
   容器里、远程打开时根本没有它，一个页面也打不开。现在这个页面把 Chromium / Chrome 放在服务端那台
   机器上，由服务端给它一块虚拟显示器，画面以帧的形式回传到网页，点击、滚动、打字按坐标与按键传回去；
   页面只重画一次（点一下、加载完）时最后那帧会再写一遍，否则画面停在点之前那张、看着像点击没生效。
   只有管理员能用——它会起进程，浏览器配置也是整机共用的。不想要它的部署设 `ADELIE_SERVER_BROWSER=off`，
   整条路都不动；浏览器不在常见名字下时用 `ADELIE_SERVER_BROWSER_BIN` 点名。

2. **服务器浏览器里用输入法打中文也能进页面。** 此前回传的只有按键，输入法先组合、再整段交出来的字
   到不了那个页面。现在画面上盖了一个看不见的输入框：点一下画面它就有焦点，输入法有地方组合，组合
   一结束就把整段文本按一次 `insertText` 送过去；组合期间那些键不再当普通按键转发，取消组合则什么都
   不发。

3. **十二处被拒的操作，原因留在原地。** 这些页面都不做乐观写入：被拒之后表单、开关、卡片、那一行
   条目一个字都不变，于是「为什么」是唯一说明按钮被按过的东西；它此前只落进一条六秒的通知，通知一走，
   屏幕上就像什么都没发生。现在每一处都把服务端的原话画在发起动作的那个控件旁边，留到下一次同一种
   写为止——同一个控件就是重试：

   - 设置 › 插件：页面读不出来时，原因画在卡片本该出现的地方（本机用自己的措辞，远程机器点名那台机器）；
     卡片保存以不点名字段的方式失败时，原因留在保存按钮上方；装完沙盒后端之后那次重读失败时，原因留在
     页面上、卡片上方，并说明卡片上的状态可能仍是安装前的。
   - 设置 › 存储台账：回收站的「恢复」「彻底删除」被拒时，原因留在那一行按钮下面，带条目编号；清理模式
     的开关被拒时说明是「开启」还是「关闭」失败，「固定」被拒时带上路径与服务端原话。
   - 设置 › 上传限额读不出来时，原因画在两个输入框上面，留到离开这一页再回来。
   - Agent 设置：记忆卡片与技能 / 保险柜 / 定时任务共用的那张卡片，「启用」开关被拒时原因留在卡片下面；
     提示条上那颗「插入占位符」被拒时，原因留在提示条正下方，按按钮自己的措辞（旧版模板是「迁移」）并
     点明是哪一个占位符；每一次「保存」前面那张确认框，等到服务器答复才关——被拒时把原话画在自己那句
     话下面，那颗确认按钮就是重试，只有真的写进去才关。
   - MCP 卡片的「测试连接」、模型库弹窗的「测试连通性」被拒时，原因画在按钮正下方，而不是六秒后消失；
     两种答复各按既有规则取词，路由不了的那条仍把被换掉的原句送进控制台。

## 兼容

- 请求、响应与磁盘格式都没有变。新增的只有服务器浏览器的接口（管理员限定）与页面，以及它自己起的
  一个 Chromium 进程；旧页面不调它，部署里关掉它也不影响别的功能。
- 新装的机器与升级的机器都不需要改配置。`ADELIE_SERVER_BROWSER=off` 可以让服务器完全不碰浏览器；
  `ADELIE_SERVER_BROWSER_BIN` 只在浏览器没装在常见名字下时才有用。
- 服务器浏览器要机器上有 Chromium 或 Chrome；没有时页面会说它不可用并给出原因，不会自己去装。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.3。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.6.2）让手机上的终端断了会自己重连，删一个大 Agent 不再卡住应用。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
