# Adelie v0.4.2 —— 别的东西也能和你的 Agent 说话：Agent API

这一版自 v0.4.1 起在 `main` 上落了 **7 个功能性提交**：一个新能力（Agent API），三处悬停与
排版的修补，一个打开历史对话的提速，一处主题细节，以及账号菜单里的一行小字。**没有破坏性改动**：
数据根（`~/.adelie/data`）、配置格式、既有 HTTP 接口都没动，已装好的机器不需要改任何配置。

主线是「Agent 不必只坐在这个界面里等你打字」。你的脚本、你自己的小工具、另一台机器上的程序，
现在可以把某个 Agent 开放出来，像调用一个服务那样跟它对话。

## 这一版改了什么

1. **Agent API：外部程序可以和某个 Agent 对话。** 在 Agent 设置里多了一个 **API** 标签页：打开
   **开启 API 访问**、给这个会话选一种审批模式、按需签发密钥（密钥只在签发那一刻显示一次，
   列表里只留前 16 个字符），旁边给出 Base URL、Agent ID 与 curl / TypeScript 两种示例。
   程序把输入发到 `POST /api/amsp/v1/agents/<projectId>/<agentId>/runs`，以事件流实时读取这次
   运行，再凭 `session_id` 接着聊——**这些运行走 Project 的模型与凭据，像普通对话一样被记录**，
   并出现在侧边栏的「后台会话」折叠夹里。不签发密钥也可以开**无密钥访问**（默认关闭，打开前会
   先弹一句警示）；管理员在 **设置 › 服务器** 里有一个总开关，关掉之后所有 Agent API 请求都被
   拒绝，各 Agent 的设置与密钥原样留着。密钥只能运行它所属的那一个 Agent，改不了任何配置：
   **把 Agent 对外开放这件事需要人的登录**，Agent 自己的 shell 里做不了。
   事件走的是新的 AMSP 协议（Agent Message Stream Protocol，SSE 的 `data:` 行，以 `data: [DONE]`
   收尾），文档里新增了 **Agent API** 与 **AMSP** 两个参考页；`@adelie/amsp` 是一个新的公开包，
   没有运行时依赖，Node 与浏览器都能用，`client.run()` / `client.ask()` 两个方法够用。
   命令行一侧多了 `penguin agent api`：`status` / `enable` / `disable` / `set`、`keys ls` /
   `create` / `rm`，以及 `server on|off`。API 标签页末尾那个**试一试**不用密钥：它按你自己的登录
   身份真的跑一次 API 运行，并把程序会收到的事件流按「渲染 / 原始」两种样子显示出来。
2. **打开一个历史对话不再排在侧栏后面。** 此前对话页要等侧栏的会话列表加载完，才去查证地址里
   那个会话，而列表按「每个 Agent、每一页」向每台服务器各发一次请求，浏览器又把同源请求排队
   ——于是一次深链接的打开排在整片请求之后。现在对话自己那一次查询不再等列表；侧栏那一侧改成
   每个服务器一条批量请求（`POST /api/projects/<id>/sessions/batch`，最多 256 条、按请求顺序作答，
   这台服务器上没有的 Agent 明确回答 `absent` 而不是被读成「没有对话」）。上游 #984 移植。
3. **承载屏幕上没有的信息的悬停提示回来了。** 悬停提示只在元素没有自己的文字、或文字被截断时
   才弹出，于是「点下去会丢掉什么」「快捷键」「文件夹名背后的完整路径」这类提示，在带可见文字
   的控件上全都不再出现 —— 头像首字母和当图标用的字母也被算成可见文字。规则现在不再把 SVG 内与
   `aria-hidden` 内的文字算作元素自己的文字，补充可见文字之外信息的提示经标记后照常显示。上游
   #1051 移植。
4. **被省略号截断的一行，悬停就能看到全文。** 页面自己截断的一行、只留末尾几段的路径、只显示
   文件夹名的工作区，原先都看不到完整值 —— 共享的提示层只对带 `data-tooltip` 的元素起反应。
   现在它会退回指针（或焦点）所在的那一行：等宽字体的路径用代码面板，其余用文字面板，空白行
   不弹；文件类工具卡片的副标题（`…/上级目录/文件`）也补上了完整路径。上游 #1069 移植。
5. **列表行的操作始终在视野里。** 上游的原始报告：Agent 设置 → 记忆里只要有一条记忆的说明很长，
   那一组的每一行都会排得比卡片更宽，于是每行的查看、编辑、删除按钮被卡片裁掉，说明很短的行也
   一样，说明再长一些连日期都被挤出去。修复落在 `packages/ui` 的共享列表行与可折叠分组上，
   所有基于它们的列表（记忆、日程、技能、插件……）随之生效；标题与说明最多一千个字符上页面，
   完整文字进悬停提示。上游 #1157（连同它依赖的 #1133 里那段换行布局）移植。
6. **极客（Console）主题的图表连线改为点间直线。** 这个主题原来用阶梯线连相邻数据点：每个值先
   横走半格、再竖跳一下，读数看上去像在自己的格子里「保持」了一段。这个主题本来就给每个点画
   方块、给每根柱子描边，值由柱子表达就够了。通用（Primer）一直是直线、白领（Frost）是平滑
   曲线，这次只有极客变。上游 #1131 移植。
7. **账号菜单里「反馈社区」下面那句小字去掉了。** 菜单是拿来点的，不是拿来读的 —— 它旁边那行
   「用户反馈」是把内容收进这台机器，这行是产品的公开板块，两个名字已经说清区别，底下再解释
   一遍只是把菜单撑长。

## 升级

桌面端（Windows / Linux 的 AppImage）在应用内更新：账号菜单的更新入口，或应用菜单里的
「检查更新」。默认的镜像源当前不可用，客户端会自动回退到 GitHub Releases；Windows 安装包仍未
签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

命令行安装（Linux / macOS / Windows）改用同一份单行安装脚本，`--version v0.4.2` 可钉住这一版。

插件不会被自动覆盖：需要的在插件市场里各自更新。**WPS 插件另说** —— 你在笔记本上改过的那份面板
（图标、字号、权限胶囊那套，技能版本 2026.10.15.2）仍只在你那台机器上，仓库里这一份是
2026.10.15.3。在笔记本上点「更新」会把它换成仓库里这一份，那一套改动会丢；要保住就先别更新它，
或让它先落进仓库。
