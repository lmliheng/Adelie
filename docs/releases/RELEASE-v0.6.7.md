# Adelie v0.6.7 —— 被拒的原因都留在原地，另外三处后台噪音不再刷日志

这一版自 v0.6.6 起在 `main` 上落了 **10 个用户看得见的改动**（其余是每轮的记账）。没有删除任何功能，
数据根、配置格式与既有接口都没有变；升级不需要做任何事。

## 这一版的新东西

### 1. 最后六处「被拒的原因只活六秒」，现在都留在发问的地方

从 v0.6.5 起一直在做同一件事：一次写入被服务端拒掉时，控件、表单、卡片一个字都不变，于是「为什么」是唯一
能说明这颗按钮被按过的证据 —— 而它此前只在页面顶部一条六秒后自己消失的通知里。这一版把这一族收尾了。

六处的宿主各不相同，因为句子得留在发起动作的东西旁边：

- **插件库卡片的「导出插件」被拒**——原因画在那张卡片里，留到下一次尝试为止；卡片上的那颗导出按钮就是重试。
  句子说的是「导出只是读取，它的文件没有被改动」，因为这次拒绝可能正是「这个插件已经不在库里」，「仍在目录里」
  会是假的。
- **记忆组的「导出」被拒**——原因画在那一组里。它要穿过折叠：按钮在标题条上，正文可能折着，所以句子落在
  标题条与正文之间，组折起来时照样看得见。
- **记忆组的「导入」选错了文件**（选中的不是记忆导出文档）——导入框根本不会打开，原因画在同一个位置。解析就在
  页面里做，一个请求都没发出去，句子如实地说「记忆一条都没有被改动」。
- **记忆一行的「查看」被拒**——面板没打开就是因为读不到，所以原因没有别处可去：它画在那一行里、那条记忆下面，
  收住这一行的横线之上。旁边文字列的宽度一寸未动。
- **输入框里的权限档没切过去**——原因画在输入卡上方（和思考等级被拒的提示同一处），并点明「会话仍是原来的
  权限」：按钮会自己退回原样，一个退回原位的按钮说不清这件事。
- **被拒的开关、插入占位符与提示词保存不再重复一条通知**——这三处上一版就已经把原因留在卡片、条或确认卡里，
  却同时保留了旧的通知，同一件事说两遍。这一版去掉的是第二遍；**写成功**的通知一条没动。

### 2. 三处后台噪音不再冒到日志里，而是记进错误中心

- **热推之后退役的那一代 machines 不再装「保持连接」的定时器。** 一次热推完全可能落在旧一代「先走网络再落定」
  的中间，那个每分钟扫一遍的定时器随后才装上，于是再也清不掉，每分钟读一个早就关掉的数据库 —— 进程日志里
  每分钟多一条没人能处理的拒绝。现在每一代自己记住「已被退役」，在每个 await 之后都看一眼。
- **那个定时器里那次重连的失败被记下来。** 它此前是「发出去不等」的写法，失败直接变成一条光秃秃的进程级拒绝；
  现在报到错误中心，用的来源与错误码和启动那一趟同一类 —— 面板上一条忽略规则就能把启动那次与之后的重试一起
  静音。退役时正在走的那趟扫描不记：被关掉的数据库是「退役」本身，不是故障。
- **「推送整队机器」连开头都没做到时，错误中心记下是哪个项目、哪一步。** 改模型配置后那趟不等人的同步，机器
  之前还要先读一遍 ssh 配置与每台机器的会话；那几步此前在那个 catch 之外，一条在那里抛错的传输就让整件事变成
  一条没有语境的拒绝 —— 面板按项目列筛选，而它不属于任何项目。现在它是 `fleet_sync_failed`，项目作为语境一起
  带上。每台机器自己的失败照旧只进连接日志。

### 3. 命令行里丢掉的响应体不再让整条命令崩掉

CLI 有五处丢掉一个没人会读的响应体（空答复、`401` 之后换 token、`human_required` 重试的两半、`penguin server`
等监听器时的就绪探测）。如果这条流在丢弃的那一瞬间已经出错，丢弃本身会拒绝，而 CLI 没有兜底处理器，Node 的
默认行为就是结束整个进程：一条只想把响应体扔掉的命令，死在自己的拒绝上，报错里还看不出是哪里。五处现在都走
同一个「吞掉这个拒绝」的助手，服务端那几处丢弃点一直是这么写的。

## 兼容

- 没有删除任何页面、路由或环境变量；没有新增环境变量。
- 数据根、配置文件格式、请求与响应都没有变化。
- 界面新增的只有几处「原因」槽位（折叠段、列表行、卡片、输入卡上方），它们不传时是空的，既有用法一个字节没变。
- 错误中心会开始出现两类新记录（`machines_reconnect_failed` 的定时器重试、`fleet_sync_failed` 的整队推送），
  它们都是可以按类忽略的。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.7。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.6.6）让错误表能忽略某一类报错，并把服务器浏览器整套删掉。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
