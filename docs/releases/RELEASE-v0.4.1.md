# Adelie v0.4.1 —— 需求箱能看见「哪些提交还没发出去」，账号菜单多了公开反馈板

这一版自 v0.4.0 起在 `main` 上落了 **10 笔提交，其中 5 个功能性改动**（另外 5 笔是每轮的记账）。
**没有破坏性改动**：数据根（`~/.adelie/data`）、配置格式、既有 HTTP 接口都没动，已装好的机器不需要
改任何配置。

这一版的主线还是「少一步手工、少一次开终端」。需求箱那一页现在自己写着仓库里哪些提交还没发版、
现网跟没跟上；想反馈问题不必先等某个后端配好，账号菜单里直接有一扇门通向公开反馈板；模型页那四个
国内分组从字母方块换成了各家自己的标记。

## 这一版改了什么

1. **需求箱页面多一块「提交同步」。** 以前要知道「提交了但没发出去的有哪些」「现网到底在跑哪一版」，
   得开终端敲 git。现在这一页自己写着三件事：**未发版**（最后一个发布标签之后的提交）、**现网没跟上**
   （已发出去、而正在跑的服务还没换上的提交，只算会进构建的提交 —— 发布正文和记账这类只动 markdown
   的不算，否则每次发完版都在喊「现网落后 1 条」）、**装了没重启**（磁盘上的版本比正在跑的进程新，
   这是单独一种状态，以前页面上完全看不出来）。现网在跑哪个版本是问服务自己的 `/api/version`，不是
   读磁盘上那份——读磁盘正好会把「装好了没重启」盖掉；那个接口要本机口令，口令只在服务进程里读，
   不下发浏览器。出处（仓库、现网地址、口令文件、安装目录）都在 `box.config.json`，安装脚本会自己推。
   插件 `@lmliheng/requirements-box` 的版本相应升到 `2026.10.15.1`。
2. **账号菜单多一行「反馈社区」。** 左下角账号菜单里新的一行打开产品的**公开反馈板**（腾讯兔小巢），
   新标签页打开，不打断当前页面。它和旁边那行「用户反馈」并排放着而不是合并：原来那行是把内容收进
   *这台机器*的反馈队列、而且只有这台机器配了反馈后端时才出现；公开板块属于产品本身，每个安装都是
   同一个地址，因此永远都在。两行的区别用一行小字「公开」标出来。
3. **小米、百度、腾讯、讯飞四家分组的图标。** 上一版把新加的四家（Xiaomi MiMo、Baidu ERNIE、
   Tencent Hunyuan、iFlytek Spark）发成首字母方块，因为没有核对得到的品牌图形——手画一个商标比方块
   更糟。这轮把四个形状逐字取回来：小米那个圆角方块的 Mi、百度的爪印、腾讯混元的环形标记、讯飞站标
   里那个徽记。四家都照别的服务商那样收成单色、纯路径、不加载任何外部图片，深浅两套主题下都读得出。
4. **限流不再藏在「网络错误」里。** provider 回 429 与连接中断此前共用 `network` 一个错误码，下游分不
   出「线路抖了一下，稍等再试」和「这个模型已经没有配额了，退避到头还是 429」——两者的处置不一样。
   `ErrorCode` 增加 `rate_limited`（`isRateLimitError` 与 `isFatalProviderRejection` 并列导出，沿错误
   `cause` 链读），结果状态仍是 `retryable`，重连阶梯、放弃时机、重试内容都没变，只是把原因命名出来。
   最直接的可见处是成本中心的错误面板：它按 `error_code` 分组，限流因此不再混在 network 那一桶里
   （上游 #1114 移植）。
5. **智能体面板：子智能体的描述比名称小一号。** 调用关系图里子节点的第二行（派生它的 `run_subagent`
   调用带来的描述）此前与上方的 Agent 名同一档字号，中文描述看上去和名称一样大甚至更大，节点上
   「先是谁、再做什么」的层次就没了。现在名称用正文字号、描述仍用小号字排在下方，三套主题都是如此；
   关系图的节点框、间距与连线也改为跟随「字号」设置按 rem 排布，此前白领主题在「特大」档会把描述
   的下沿截掉（上游 #1096 移植）。

## 升级

桌面端（Windows / Linux 的 AppImage）在应用内更新：账号菜单的更新入口，或应用菜单里的「检查更新」。
默认的镜像源当前不可用，客户端会自动回退到 GitHub Releases；Windows 安装包仍未签名，SmartScreen
会提示一次（「更多信息 → 仍要运行」）。

命令行安装（Linux / macOS / Windows）改用同一份单行安装脚本，`--version v0.4.1` 可钉住这一版。

插件不会被自动覆盖：需要的在插件市场里各自更新。**WPS 插件另说** —— 你在笔记本上改过的那份面板
（图标、字号、权限胶囊那套，技能版本 2026.10.15.2）仍只在你那台机器上，仓库里这一份是 2026.10.15.3。
在笔记本上点「更新」会把它换成仓库里这一份，那一套改动会丢；要保住就先别更新它，或让它先落进仓库。
