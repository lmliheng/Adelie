# Adelie v0.8.1 —— 两个分组换上真标记，桌宠那条鱼改了名

这一版在 v0.8.0 上收尾，没有新页面。模型库里上一版刚加的两个分组——**Venice AI** 与**腾讯
TokenHub**——当时画的是灰底字母牌，现在换成了它们各自的标记；「被拒的原因，留在你按下去的地方」
这一族又把模型页剩下的两处收完；命令行不再无条件把颜色关掉。

桌宠的第二个形象这次动了画面：上一版那条蓝色小鲸鱼改画成了**蓝色大肥鱼**——更胖更圆、两只大眼睛、
白肚子——选项名也跟着改了。企鹅仍是默认的那一个。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.8.1。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**两个分组换上真标记。** **Venice AI** 画的是它自己的标记（两把交叉的钥匙，上方一枚展开的翼），
**腾讯 TokenHub** 画的是腾讯云的云朵标 —— 它本来就是腾讯云自己的模型网关，key 与控制台都挂在腾讯云
账号下，用腾讯云的标既真实、又正好和紧挨着的「腾讯混元」（画的是混元的圆环）区分开。两枚都和别的
预置服务商一样是单色，跟随浅色/深色主题。**没有自己描**：标记取自 `@lobehub/icons` 发布的资产原样
拷入，与前几次一样不新增依赖。

**桌宠那条鱼改画了。** 「设置 › 外观」里「桌宠形象」的第二个选项，上一版是一条按官方鲸鱼标志侧影想
的蓝色小鲸鱼，现在画的是**蓝色大肥鱼**：更胖更圆的身子、两只大眼睛、一大块浅色肚子。选项名也从
「蓝色小鲸鱼」改成「蓝色大肥鱼」。**选过它的机器照旧选中它** —— 存在浏览器里的那个名字没变，只是画
法与显示名换了。

**「被拒的原因，留在你按下去的地方」又收了两处。** 模型库分组表头上的「填写密钥」被服务端拒绝时，
过去原因是六秒就走的一条通知、而那把刚敲进去的密钥已经跟着框一起不见了；现在框站着、密钥仍在字段
里、服务端原话画在字段上方，确认按钮就是重试。Penguin Go 分组的「同步」被拒时，原因也不再只闪一下，
而是留在那个分组自己的表头下面。

## 值得一提

- Agent 用 `exec_command` 启动的命令不再无条件收到 `NO_COLOR=1`：宿主环境里有就照常继承，没有就不给。
  想保持旧行为，在密钥保险柜里设一个 `NO_COLOR` 即可；想强制上色设 `FORCE_COLOR`。管道里的输出仍不
  会被刷成 ANSI 转义串（`FORCE_COLOR` / `CLICOLOR_FORCE` 照样从子进程环境里移除）。
- 桌宠形象是浏览器偏好（跟主题、字号一族），所以它跟着这个浏览器走，不写进桌面壳的配置里。
- 这两个标记是纯路径，没有新增图片或字体资源。
- 上一版的两个新分组与管理员通知都不受影响，升级后照旧。

## 兼容

- 没有新的数据库迁移：这一版不含表结构改动，回滚得住。
- 没有删除任何页面、路由或环境变量；接口形状、数据根与配置文件格式一个字节没动。
- 升级不需要做任何事。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.8.0）加了管理员通知与可选的桌宠形象；那一版桌宠多了一条语音通话，安卓端第一次成包。
