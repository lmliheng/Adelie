# Adelie v0.8.2 —— 别的服务能认出「这个人是谁」，桌宠面板不再被切掉

这一版给 Adelie 开了一扇**对外的门**：服务器上的其他程序（另一个后端、一个脚本、一个定时任务）可以拿一把
用户自己铸的令牌，问一句「这是谁」，拿到昵称与头像。它就是 Web 应用里那个「用某某登录」的后半段 ——
这一版只做**服务器端**那一半，页面上没有任何新增。

其余是把上一版留下的几处小事收干净：桌面壳里的桌宠面板不再被窗口切掉第一行，两处「被拒的原因」
也终于留在你按下去的地方。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.8.2。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**别的服务能认出「这个人是谁」。** Adelie 的身份层本来就在（scrypt 哈希、可撤销会话、四种凭证各有
边界），这一版把它**对外**铺开：服务器上的外部程序可以问「这把令牌属于哪个用户」。用户自己铸造令牌
——命令行一条 `penguin auth pat --user-id … --name "需求箱"`，或者管理员走 HTTP 口，或者自己在
「我的」里看和撤销 —— 令牌的形态是 `adelie_pat_` 加 32 字节随机数，**数据库里只存它的 sha256**，
带用途名、范围、到期时间与最后使用时间。

外部应用拿两个端点换身份：`POST /oauth/introspect` 把令牌换成 `{"active":true,"sub":…,"name":…}`，
`GET /oauth/userinfo` 是只想拿昵称头像时的直路。这把令牌**只回答身份，不回答能力** —— 它打不开
`/api/*`，读不了会话、也跑不了一轮 Agent；那是 Agent API 的事，两者正交，谁也不替谁。

**桌宠的面板不再被窗口切掉。** 桌面壳右上角那个桌宠面板，「打电话」那一行加进去后成了第四行，而窗口
高度还停在 248：多出来的那行被顶到上沿、再被裁掉一半，看着像「第一行没了」。现在窗口放到 300，面板
自己也会按剩余高度封顶，过长的提示在面板里滚动。顺手删掉了那只**自绘**的蓝色大鱼 —— 桌宠形象只剩
「企鹅」和「我的图片」，之前选过自绘鱼的偏好会自动回落到企鹅。

**「被拒的原因，留在你按下去的地方」收了最后两处。** 频道里邀请人被拒时，过去选择器立刻关闭、原因是
一条六秒就走的浮动通知，通知没了既不知道原因、也没有那一行可以重试；现在选择器留到写入落定才关，
搜索词还在、原因逐字画在那位候选人的行下面，同一行就是重试。模型页的分组则一律**从折叠开始** ——
过去它悄悄替你展开排第一的那个分组，目录长到二十几个之后这个猜测不再成立，现在一个都不展开，与
侧栏自己的分组集合同一条规则；搜索仍会临时展开命中的分组。

## 值得一提

- **这一版有一处数据库迁移**（第 17 号，新增 `user_tokens` / `oauth_clients` / `oauth_audit` 三张表，
  不动已有表），开服务时自动完成，回滚得住。
- 对外的三个端点挂在 `/oauth/*`，**不在 `/api/*` 下**，也不需要新的环境变量；它们只收表单编码的
  请求，**没有开 CORS**，所以是服务器到服务器的通道，不是给浏览器页面直接调的。
- 内省端点要外部应用带上自己的 `client_id` / `client_secret`（HTTP Basic 或表单字段）：这样撤销能按
  应用做、审计能归因到「哪个应用、什么时候、用谁的令牌、问了什么」，内省也不会变成令牌探测器。
  凭证不对是 401；令牌那边的**任何**情况（不存在、过期、撤销、账号没了）都折合成同一句
  `{"active":false}`，不区分。
- 命令行多了一个子命令 `penguin auth pat`（铸长期令牌）；原来的 `penguin auth token` 不变，它铸的是
  短期会话令牌并写进 `cli-session.json`。
- 文档多了一页 [鉴权：外部应用接入](https://lmliheng.github.io/Adelie/docs/external-auth)。

## 兼容

- 数据库有一处迁移（第 17 号，只新增三张表），升级时自动跑。
- 没有删除任何页面、路由或环境变量；接口形状、数据根与配置文件格式一个字节没动。
- `/api/*` 的鉴权口径没变：新铸的个人访问令牌拿它打不开。
- 选过「自绘蓝色大鱼」桌宠形象的浏览器，偏好会回落到企鹅 —— 这是唯一的可见回落。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.8.1）给两个模型分组换上了各自的标记，并把桌宠那条鱼改名；再上一版（v0.8.0）加了管理员
通知与可选的桌宠形象。文档在 <https://lmliheng.github.io/Adelie/docs/>。本版全文见
[`docs/releases/RELEASE-v0.8.2.md`](https://github.com/lmliheng/Adelie/blob/main/docs/releases/RELEASE-v0.8.2.md)。
