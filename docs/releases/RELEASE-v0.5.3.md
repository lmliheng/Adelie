# Adelie v0.5.3 —— 被拒绝的原因留在框里，桌宠真的拖得动

这一版自 v0.5.2 起在 `main` 上落了 **39 笔提交，其中 9 个用户看得见的改动**（其余是浏览器用例的稳定性
与每轮的记账）。数据根、配置格式、包名与既有 HTTP 接口都没有变化，装好的机器升级后不用改任何配置。

一条主线贯穿十几个页面：**写入被服务器拒绝时，原因就留在你刚按下的那张确认框里**，而不是变成一条六秒
后自己消失、还浮在框上方的提示。另一条是上一版那只桌宠 —— 它从「能看」变成「能动」。

## 这一版改了什么

1. **桌宠拖得动，点它有反应，也不再是一张静止的画。** 上一版那只企鹅其实拖不动：窗口上盖着一整片系统
   拖动区，偏偏把企鹅挖了出去（为了让点击落到页面上），而企鹅是透明窗口上人唯一摸得到的地方 —— 看得见
   的桌宠正好就是拖不动的那部分。现在**企鹅自己就是把手**：按住它移动就挪动窗口，按住不动就是一次点击，
   开合面板并让企鹅跳一下。它还会自己眨眼，瞳孔跟着指针转；跳跃在点击和收到通知时都播，于是「注意到了」
   是看得见的，而不只是读得到的。系统里要求减少动效时，眨眼、摇晃与跳跃随其它动画一起关掉，瞳孔仍然
   跟着指针（那是一个位置，不是一段补间）。窗口其余部分的拖动区照旧，此前拖得动的地方现在还是拖得动。

2. **被拒绝的原因画在确认框里。** 模型库里六个写着配置的确认框 —— 保存模型的配置、设为默认模型、设为
   视觉代理模型、删除模型、删除分组、同步预置 —— 现在把服务端那句话画在框里、句子下面、重试按钮上方，
   落款「操作被拒绝：」。此前它只出现在一条 toast 里：最需要它的时候（看完原因再决定要不要重试）往往
   已经消失了。

3. **删除模型和保存模型配置：写成功才收起那张框。** 这两张确认框此前在请求发出时就关闭，**不管写没写
   成**，而页面会先摆出「尝试中」的那张表。于是被拒的一次删除让模型从页面上消失、服务器却还留着它，连
   打开卡片的入口也没了；被拒的一次改名让页面显示着服务器没接受的名字。现在写入有结果才收起，被拒时
   卡片、那一行和原来那张表都原样留着，重试就是同一个按钮。

4. **同一条规矩铺到另外五个地方。** 删除定时任务（项目定时任务页、对话侧栏的定时任务面板、Agent 设置页
   的定时任务表三处界面）、评估中心删除 Benchmark、插件市场安装或移除模块插件、侧栏删除对话：被拒时
   卡片留着它的句子，原因画在下面，不再弹一条自己会消失的提示。仍用提示条的是几处**没有框可以留**的
   写入 —— 分组密钥、工具栏上的「同步预置」、定时任务的启停开关、插件页的批量更新与单 Agent 操作，以及
   可能删一半的批量删除对话。

5. **新对话页的版本行会写出最新发布版。** 落后两个版本的安装此前看不出来自己落后了：那一行只写正在
   运行的版本，新版号藏在旁边上标的悬停提示里。现在检查到更新的发布版时，这一行直接接着写
   「最新版本 vX.Y.Z」；已经是最新就不重复写。

6. **浏览器用例不再在动画中途量尺寸。** 三个用例（竖栏折叠、停靠栏与弹入面板、缩放后的取样）改成等过渡
   落定再断言，此前偶发的红与真实缺陷无关。这一条用户看不见。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上 24 个包都到了
0.5.3。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.5.2）给桌面版加了桌宠、让结束的定时任务自己移进 `expired/`、MCP Server 可以停用而不必删除；
再往前（v0.5.1）把阿里云镜像彻底停掉，发布只剩 GitHub 一个地址。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`changelog/unreleased/`](https://github.com/lmliheng/Adelie/tree/main/changelog/unreleased)。
