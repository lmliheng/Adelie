# Adelie v0.8.6 —— 大文件不再塞进消息正文，对话页多了「网络」面板

附一个上百 MB 的文件发送时，它不再跟着消息正文一起走：超过 2MB 的每个文件先单独传进这个会话的暂存
区，消息里只带一个落盘路径，上传时右下角有一张进度卡。对话页的停靠区多了一个常驻的「网络」标签，每一
回合发了哪些请求、多久、收到多少帧都看得见，密钥默认打码、只在页面内存里。内置提示词也推进了一代
（内核 2026-11-27）：交付物要拿用户的明确要求去核对，检查卡住时先分清原因再重跑。另有一批小修。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.8.6。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**大文件附件走自己的上传通道。** 以前一条消息的附件是以 base64 塞在请求正文里的，一个 177MB 的文件
就是一次约 236MB 的请求：只有整份发完浏览器才说得出「已发出」，慢网下输入框一禁用就是几分钟。现在
2MB 以上的文件在发送时逐个直传进会话的暂存区（边收边落盘，超出上限当场断开并删掉半截文件），消息里
只带一个指向它的路径；每个文件一张进度卡，传失败就是这次发送失败，草稿和附件都留着，按钮就是重试。
2MB 以下照旧内联，截图和短日志不会为此多一个来回。

**对话页的「网络」面板。** 停靠区多了一个常驻的「网络」标签，和子代理、文件、记忆、轨迹、日程并列：
不用先打开开关，记录只在本页内存里、刷新即清空。列表按回合分组，每行是时间、方法、状态、路径、帧数
和耗时；失败的标红，重试的带 `×n`，慢请求有标签。可以切范围（本次回复 / 最近 5 回合 / 全部）、按类型
筛选（接口 / 模型 / 流 / 上传）、按路径或状态码搜索。点一行在面板内看详情：概述（时间分解）、请求头与
请求体、响应、事件流，以及这一回合的其它请求；`authorization`、`cookie`、各种 token 默认打码，要看
原文得二次确认。助手回复的页脚也多了 `⚡ N 个请求 · M 次模型调用 · 耗时`，点它直接开到这个回合。

**内置提示词：交付物自己核对，卡住的检查先分清原因。** 「成功标准」原来只说「检查每个问题都解决了」，
没说拿什么去比，字面量、路径、筛选条件差一点也可能被报成「已验证」；现在写明要拿用户的明确要求核对，
项目文档里的检查照跑、覆盖不到的补一个针对性的检查，并且只报观察到的结果。提示词动过了，内核版本
跟着推进到 2026-11-27。

## 值得一提

- 悬停提示里没有断点的长串会在面板边缘折断，不再跑出面板；回复里的表格在窄屏下不再被挤成一字一行。
- 桌宠语音通话失败时说的是这个窗口的语言，关闭原因不再覆盖那句话。
- `input_subagent` 留在后台的续跑轮，完成时会回报一次。
- 停靠面板里开终端、清空数据的第一步、以及工作区选择器的地址栏：失败的原因都留在原地，不再只挂在
  一条会自己消失的通知上。
- 手绘涂鸦主题下，「运行中发送方式」的选中按钮与工作区选择器里选中的那一行，不再被自己的底色吃掉。

## 兼容

- 这一版**没有数据库迁移**，数据根与配置文件格式一个字节没动；数据根与上一个版本互相兼容。
- 服务端新增了一条上传路由，旧的请求方式（附件的 base64 内联）照旧可用；同时更新的前端与后端之间没有
  先后要求。
- 内置浏览器连接协议仍是第 2 版，与 v0.8.5 的桌面应用互相兼容。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.8.5）给大附件的上传加了进度卡、把打不开的原因留在原地；再上一版（v0.8.4）给内置模型库补上
Google Gemini 4 的四条、把桌宠的实时语音通话改成气泡对话。文档在
<https://lmliheng.github.io/Adelie/docs/>。本版全文见
[`docs/releases/RELEASE-v0.8.6.md`](https://github.com/lmliheng/Adelie/blob/main/docs/releases/RELEASE-v0.8.6.md)。
