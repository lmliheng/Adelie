# Adelie v0.6.12 —— 被拒的原因留在你按的地方，频道里的消息按自己的日子归位

v0.6.12 自 v0.6.11 起落了十一个修复，大半是同一件事的收尾：一次保存、一次发送、一次导入被拒时，
过去只有页面顶上一条六秒就走的通知——等你把眼睛转回按钮，屏幕上已经没有任何字说得出刚才发生了什么。
现在句子画在你按的那颗按钮旁边，留到下一次尝试为止。另外两处：换布局不再弄丢消息绑定面板里打到一半
的凭据，频道里实时到达的一行按它自己的日文件归日。

没有删除任何页面、路由或环境变量；数据根、配置格式与请求响应都没有变。升级不需要做任何事。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.6.12。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**被拒的原因，现在留在你按下去的地方。** 界面上有一批开关与按钮不做乐观写入——状态要等服务端点头
之后才动；这本身是对的，可一旦服务端拒绝，按钮就停在原地、什么都不变，而原因此前只有一条 toast，
六秒之后自己消失。用户看见的便是一颗点了没动的按钮，和一句已经看不见的解释。这一版把这一族的最后
几处收尾：话留在发起动作的那一处，留到下一次尝试、一次成功或者重新打开那个对话框为止。

**挑进来的附件、翻不到的频道、读不出来的目录，也一样。** 挑到一张过大的图片或一个过大的附件时，
输入框在读文件之前就拒掉它：没有 chip、草稿一个字没加——原因画在输入卡上方、整排拒绝句最前面。点
「更早的记录」而那一天没读回来时，原因画在按钮正下方；打开频道时首屏是「今天 + 逐日往回」拼出来的，
回走中途被拒过去是无声地用走到的那点内容渲染，安静频道上就只剩今天，现在复用同一句文案和同一个槽位。
文件面板里根以下的目录那一次读失败时，过去是弹一条通知、同时把那一行从树上删掉——六秒之后，树上既
没有一个字说这个目录还在，也没有一个字说刚才怎么了；现在那一行留在原处、仍然展开着，原因用危险色写
在它下面，点那一行就是重试。

**换布局不再丢掉消息绑定面板里没保存的改动。** 那张表单是编辑器自己的组件状态，跨断点（右侧栏 ↔
窄屏合并面）时整份重新挂载，从服务端读回一份干净的：粘进去的机器人 token、敲进去的 App ID、切过去
的渠道都只活在旧那份挂载里。现在按会话记一份，只有落到另一个停靠面才交回；表单与服务端一致时（没敲
东西、或刚保存过）记录删掉。

**频道里实时到达的消息，按它所在的日文件归日。** 频道收到实时事件就把消息追加进流里，而事件过去只
说哪个频道的哪条消息、不带它来自哪个日文件，于是视图把每一条到达都算成今天：此刻正在发的那条是对的，
扫描器广播出来的其它行都不对——CLI 或手改往昨天日文件里追加的一行、午夜前一秒写出午夜后才被广播的
一行，会画进已打开频道的「今天」那一段，刷新后又回到它自己的日子。现在事件带上读出来的那个日文件
（组织时区），视图按它归日；首屏没拉过的那一天按日期顺序插到该在的位置。存储格式、路由与重新拉取的
路径都没动。

## 值得一提

- **组织设置的 Save**，以及对话框自己那条暂停 / 恢复的 PATCH 被拒时，对话框一直开着，原因却落进
  六秒通知，草稿看起来像已经写回去了；现在服务端的话留在 Cancel / Save 那一行的页脚上（危险色、两行、
  整句挂悬停）。
- **频道发送**没发出去时，原因画在输入框上方、发送按钮的正上方；词典认识的错误码用词典的话，不认识
  就照抄服务端。句子连着频道记，换频道就清掉，不会跟去别的频道。
- **上传限制**那一页的两个数字由一次 PUT 一起写，其余任何失败画在 Save 那一行上方。
- **语音输入**那一页收成同一个形状：它原来那句只在「不是 ApiError」时才响，而网络失败也被包成
  ApiError，那条分支从没到过。
- **主题导入**超过 256 KB 的文件在浏览器读第一个字节之前就被拒，浏览器读取失败也走同一条路；两句现在
  都画在弹窗自己身体里、选择框下面。
- **编辑器草稿**超过写入上限时，原因留在表头下面，不再只是一条通知。
- **附件上限**是三个数（图片 20MB、视频 32MB 编译在服务端、附件走管理员可设的单文件上限），一次手势
  可能同时越过两个，所以句子按上限分组、每组一句，名字保持挑选顺序。
- **改名与删除**时，文件树里那条失败的原因跟着走，条目没了它的原因一起丢掉；根目录的失败不变——它
  没有一行可以挂，仍是整块替换掉树。

## 兼容

- 没有删除任何页面、路由或环境变量；没有新增环境变量。
- 数据根、配置文件格式、请求与响应都没有变化。
- 上面那些原因只是把原来吞掉的失败显示出来，保存、发送、导入、翻页的行为都没有变。
- 消息绑定面板的记录只活在当前标签页里，关掉标签页就没了，也不写进磁盘。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

## 安卓端的 Adelie

与此同时，安卓端的 Adelie 也做出了第一个内测包：整包自带运行时（arm64，约 96 MB），引擎全在手机上跑、
不连任何服务器；不进应用商店、也没有签名，安装时系统会提示「来自未知来源」。它只在内测渠道，和桌面端
这次更新互不依赖——手机上那个 App 不会因为桌面端升级而变化。工程已经收进这个仓库。

上一版（v0.6.11）让窗口跨过窄屏与桌面之间那条线之后，你在各个面板里的位置都还在。文档在
<https://lmliheng.github.io/Adelie/docs/>。本版全文见
[`docs/releases/RELEASE-v0.6.12.md`](https://github.com/lmliheng/Adelie/blob/main/docs/releases/RELEASE-v0.6.12.md)。
