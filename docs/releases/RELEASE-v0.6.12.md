# Adelie v0.6.12 —— 被拒的原因留在你按的地方，频道里的消息按自己的日子归位

这一版自 v0.6.11 起落了 **十一个修复**，大半是同一件事收尾：一次保存、一次发送、一次导入被拒时，
过去只有页面顶上一条六秒就走的通知，等你把眼睛转回按钮，屏幕上已经没有任何字说得出刚才发生了什么。
现在句子画在**你按的那颗按钮旁边**，留到下一次尝试为止。另外两处：换布局不再弄丢消息绑定面板里
打到一半的凭据，频道里实时到达的一行按它自己的日文件归日。

没有删除任何页面、路由或环境变量；数据根、配置格式与请求响应都没有变；升级不需要做任何事。

## 这一版的新东西

### 1. 保存、发送、导入被拒时，原因就在那颗按钮旁边

- **组织设置**：Save，以及对话框自己那条暂停 / 恢复的 PATCH，被服务端拒了以后对话框一直开着，原因却
  落进六秒通知，草稿看起来像已经写回去了。现在服务端的话留在 Cancel / Save 那一行的页脚上（危险色、
  两行、整句挂悬停），留到下一次尝试、一次成功、或者重新打开对话框。
- **频道发送**：消息没发出去时，原因画在输入框上方、发送按钮的正上方，留到下一次按下为止；词典认识的
  错误码用词典的话，不认识就照抄服务端。句子连着频道记，换频道就清掉，不会跟去别的频道。
- **上传限制**：两个数字由一次 PUT 一起写，其余任何失败现在画在 Save 那一行上方；语音输入那一页收成
  同一个形状（它原来那句只在「不是 ApiError」时才响，而网络失败也被包成 ApiError，那条分支从没到过）。
- **主题导入**：超过 256 KB 的文件在浏览器读第一个字节之前就被拒，浏览器读取失败也走同一条路；两句
  现在都画在弹窗自己身体里、选择框下面，留到下一次选择为止。
- **编辑器草稿**：超过写入上限时，原因留在表头下面，不再只是一条通知。

### 2. 挑进来的附件被拒时，原因在输入卡上方

挑到一张过大的图片、一段过大的视频或一个过大的附件，输入框在读文件之前就拒掉它：没有 chip、草稿
一个字没加。现在原因画在输入卡上方、整排拒绝句最前面，留到下一次挑 / 粘 / 拖为止。三个上限是三个
数（图片 20MB、视频 32MB 编译在服务端、附件走管理员可设的单文件上限），一次手势可能同时越过两个，
所以句子按上限分组、每组一句，名字保持挑选顺序。

### 3. 翻看频道没读全时，原因留在按钮下面

- 点「更早的记录」、那一天没读回来时，原因画在按钮正下方，留到下一次点击或者换频道为止。
- 打开频道时首屏是「今天 + 逐日往回」拼出来的，回走中途被拒时过去是无声地用走到的那点内容渲染，
  安静频道上就只剩今天。现在复用同一句文案和同一个槽位，画在「更早的记录」按钮下面。

### 4. 文件树里读不出来的目录，留着那一行

文件面板第一次打开某个目录时才去列它。根以下的目录这一次读失败时，过去是弹一条通知、同时把那一行
从树上删掉——六秒之后，树上既没有一个字说这个目录还在，也没有一个字说刚才怎么了，读者的位置被一次
失败拿走了。现在那一行留在原处、仍然展开着，原因用危险色写在它下面；点那一行就是重试。改名时原因
跟着走，删掉条目时它的原因一起丢掉。根目录的失败不变：它没有一行可以挂，仍是整块替换掉树。

### 5. 换布局不再丢掉消息绑定面板里没保存的改动

消息绑定面板的表单是编辑器自己的组件状态，跨断点（右侧栏 ↔ 窄屏合并面）时整份重新挂载，从服务端
读回一份干净的：粘进去的机器人 token、敲进去的 App ID、切过去的渠道都只活在旧那份挂载里。现在按
会话记一份，只有落到另一个停靠面才交回；表单与服务端一致时（没敲东西、或刚保存过）记录删掉。

### 6. 频道里实时到达的消息，按它所在的日文件归日

频道收到实时事件就把消息追加进流里，而事件过去只说哪个频道的哪条消息、不带它来自哪个日文件，于是
视图把每一条到达都算成今天。此刻正在发的消息是对的，扫描器广播出来的其它行都不对：CLI 或手改往
昨天日文件里追加的一行、午夜前一秒写出午夜后才被广播的一行，会画进已打开频道的「今天」那一段，刷新
后又回到它自己的日子。现在事件带上读出来的那个日文件（组织时区），视图按它归日；首屏没拉过的那一天
按日期顺序插到该在的位置。存储格式、路由与重新拉取的路径都没动。

## 兼容

- 没有删除任何页面、路由或环境变量；没有新增环境变量。
- 数据根、配置文件格式、请求与响应都没有变化。
- 上面那些原因只是把原来吞掉的失败显示出来，保存、发送、导入、翻页的行为都没有变。
- 消息绑定面板的记录只活在当前标签页里，关掉标签页就没了，也不写进磁盘。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.12。
