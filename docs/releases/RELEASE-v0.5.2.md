# Adelie v0.5.2 —— 桌面版多一只桌宠，定时任务自己归档

这一版自 v0.5.1 起在 `main` 上落了 **34 笔提交，其中 11 个用户看得见的改动**（其余是浏览器 e2e 与
每轮的记账）。数据根、配置格式、包名与既有 HTTP 接口都没有变化，装好的机器升级后不用改任何配置。

主线有两个：桌面版多了一只会报事的桌宠，以及「跑完的定时任务」不再堆在列表里。顺带把这一周在
界面上踩到的几处「说成功其实没成功」逐个修掉。

## 这一版改了什么

1. **桌面版能养一只桌宠。** 主窗口所在屏幕的右下角蹲着一只阿德利企鹅，透明、置顶、无边框，压在
   其他窗口之上。它会用一句话报出：定时任务触发了（带任务名）、有几个工具调用在等批准、同事的花费
   接近或超过预算；点开面板能看最近五条、账号上固定住的分组余额与刷新动作，以及客户端更新状态
   连同那个状态唯一能做的动作。**默认关闭** —— 它是一扇会盖住别的应用的窗口，设置 › 外观（托盘
   开关旁）或桌宠自己的面板里打开、收起，两处写的是同一份偏好。
2. **MCP Server 可以停用而不必删掉。** Agent 设置里的 MCP 区块每行多了一个开关：关掉后条目与它的
   每个字段都留在配置里，但任何一轮都不会连接它，它的 `mcp__*` 工具也从工具列表里消失。此前想让它
   「别再每轮都连一次」只能删掉再重填，插件装上的桥（比如 WPS 加载项）于是即使不用也一直留在每一轮
   对话里。同一个字段也可以在 `system_config.yaml` 里手写。
3. **结束的定时任务移进 `schedule/expired/`。** 已触发的一次性任务、服务器停机期间错过时间的一次性
   任务、以及已过结束时间的任务，文件原样移进该 Agent 的 `agent_state/schedule/expired/`，不再出现在
   任何列表、计数、侧栏闹钟与 `{{SCHEDULE_LIST}}` 里。同名文件加时间戳后缀，不覆盖任何东西；把文件
   移回 `schedule/` 就当新任务重新登记。**注意**：开始时间已过的一次性任务现在直接拒绝（400），不再
   「立刻执行一次」—— `penguin schedule add --start-at now` 要带上 `--period`。
4. **切换 Project 不再显示、也不再询问上一个 Project 的 Agent。** 机器慢的时候尤其常见：智能体页会
   把刚离开的项目里的 Agent 列在新项目下，还能打开它的设置；切换时打开着的对话会留在新项目里。
   现在每个 Project 范围的应答都带着发起时的 Project，过期的应答一律丢弃。
5. **成本中心的「清空错误记录」删的正是确认框写下的那几条。** 那个数字此前取的是仪表盘加载时的快照，
   而加载成本中心本身就会记一条错误 —— 写着「1 条」的确认框删掉了 2 条。现在点开确认框时重新读一次
   计数，删除停在这次读得到的最新一条上；背后的统计也跟着刷新，屏幕上两个数字不再互相矛盾。
6. **模型页两处确认框：写成功之后才收起。** 「现在升级」同步预置、自定义分组的「删除分组」此前在
   请求发出时就关闭确认框，被拒之后页面上是一张「看起来已经同步过」「分组已经没了」的表，而服务器
   还留着旧数据：重试算出空差量、一个请求都不发，删除入口跟随分组一起消失。现在写入有结果才收起，
   被拒时退回写入前的样子，错误照旧显示服务端那句话。
7. **下侧栏的拖拽边界整条都能抓。** 那条 6 px 的拖拽带过去有一半伸在框架外面被 `overflow-hidden`
   裁掉，屏幕上看到的边界线恰好落在被裁掉的一侧，按下去毫无反应。现在整条贴在内侧。
8. **Windows 上桌面版的任务完成通知真的会弹了。** 桌面端此前根本没申请通知权限，所以那条通知
   从来不会出现。
9. **WPS 加载项的桥不再对着一个已经不在的会话每 10 秒重连一次。** 会话流返回 404/410 时停止订阅并
   记一条 info。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。桌宠默认关闭，想要的话去设置 › 外观打开。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上 24 个包都到了
0.5.2。

**定时任务**：如果你有「开始时间设在过去的一次性任务」这种脚本用法，改成给一个将来的开始时间并
带上周期；已经落在磁盘上的过期任务，会在升级后的第一次对账里自己移进 `expired/`。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.5.1）把阿里云镜像彻底停掉，发布只剩 GitHub 一个地址；再往前（v0.5.0）包名改挂
`@adelie/*`。文档在 <https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`changelog/unreleased/`](https://github.com/lmliheng/Adelie/tree/main/changelog/unreleased)。
