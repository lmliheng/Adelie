# Adelie v0.5.5 —— 被拒绝的原因继续留在框里，主题能自己导入，图太多不再整条失败

这一版自 v0.5.4 起在 `main` 上落了 **29 笔提交，其中 12 个用户看得见的改动**（其余是每轮的记账与
CI 说明）。数据根、配置格式、包名与既有 HTTP 接口都没有变化，装好的机器升级后不用改任何配置。

## 这一版改了什么

1. **「原因随框留着」这条线铺到了最后八处。** 一个操作先问一句「确定吗」，这是各处都有的做法；
   出问题的是**问完之后**：卡片在请求返回的那一刻就关，不管写没写成功。被拒的时候服务端只回一句话，
   界面把它画成一条六秒后自己消失、还浮在别处的 toast —— 六秒之后，用户面对的仍是同一个问题，
   屏幕上却没有任何一句说明它为什么没做成。这一版把最后八处统一改掉：**只有写成功才关框**，被拒就把
   服务端那句话画在句子下面，重试还是同一个按钮，重新打开不带着上一次的旧原因。八处是：卸载技能、
   卸载钩子包、删除插件 / 单个智能体的卸载与更新、提示条上两条「现在升级」（插件批次与内核批次）、
   两张凭据表（智能体密钥与用户密钥）的删除、记忆页签的删除与导入、文件面板的新建 / 重命名 / 删除、
   项目设置里的「删除项目」。批量操作那条还多一层：删成一半时被拒的行留着勾，框里的条数正好是
   「重试会动到的那几条」。

2. **主题可以放进数据根，由界面自己列出来。** 主题一直只是给 UI 的令牌名一组取值，组件从不问
   「现在是哪个主题」，所以以数据形式来的主题能重画整个应用 —— 不用重新构建、不用插件、没有会跑起来
   的代码。把一个 JSON 文件放进 `<数据根>/themes/`，下一次刷新页面它就会出现在**设置 › 外观**的主题
   列表里，和自带的三套并列；删掉文件它就消失。

3. **模型库里多了 Abliteration 分组。** 那家服务卖的「abliterated」模型（在开源权重上去掉拒答倾向的
   微调版本）现在有自己一组，排在 vLLM 前面。已有的项目点一次**同步预置**就有，新建的项目直接带着。

4. **会话里的图太多时不再整条报错，只带最新的四张。** 那个模型一次请求最多收四张图，超过就整条拒掉；
   而对话里的图会被之后的每一次请求重新带上 —— 一个会话只要读过五张图，从此每说一句话都失败。
   现在发送时只带最新的四张，**这一轮自己输入的图本身就超过四张时也先裁再发**，所以已经在错误里卡住
   的会话重放一下就能接着说。历史本身一个字没改：被换掉的只是**发出去的那一份** —— 旧的图在那里变成
   一行「图片已省略」的占位，会话与 Trace 里的东西一张不少。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上 24 个包都到了 0.5.5。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.5.4）把「写入被拒绝的原因」铺到插件设置、批量删除与删除 MCP Server，并给组件库加了一族
GPU 背景；再往前（v0.5.3）铺到模型库、定时任务、评估中心、插件市场与删除对话，并让桌宠真的拖得动。
文档在 <https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
