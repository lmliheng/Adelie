# Adelie v0.8.0 —— 管理员能发通知了，桌宠可以换形象

v0.8.0 补上了一条过去一直缺的通道：管理员写给账号的**通知**。写一条标题加一段正文，发给全部账号或
点名一个；收件人在左下角账号菜单里看到带未读徽标的一行，点开就是收件箱，自己标已读。通知是**存下来
的**，不是往哪儿推一条消息就走 —— 发出之后才建的账号同样看得到。另一件脸上的事是桌宠的模样可以挑
了：默认仍是那只企鹅，想换就换成一条蓝色小鲸鱼，在「设置 › 外观」里切，当场生效。

模型库里多了两个分组：Venice AI 与腾讯 TokenHub。除此之外，「被拒的原因，留在你按下去的地方」这
一族把公司页与机器页剩下的几处收完了，外置主题在被自己样式盖住的那类机器上也修好了。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.8.0。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**管理员能发通知了。** 在「设置 › 服务器 › 通知」里写一条：范围选**全体**（包含之后新建的账号）或
**指定账号**（下拉里挑一个），填标题与正文，发出去。收件人在左下角账号菜单里看到「通知」这一行，旁边
是未读数；点开是收件箱，可以逐条标已读，也可以一次全标。发出去的同时，如果对方正好开着会话，人的
徽标**不用刷新**就变了 —— 这条实时消息只是顺手推的，真正可靠的那一份是服务端的收件箱，所以关着页面
的人下次打开照样看得到。管理员那边还有一张已发送列表，每条写着多少人读过、可以撤回。桌面模式是单
用户，没有人能发给你，这一行与设置页都不出现。

**桌宠的模样可以挑。** 一直是画死在代码里的一只企鹅，现在有第二种：圆身子的蓝色小鲸鱼。「设置 ›
外观」在「桌面宠物」开关下面多了一行「桌宠形象」，只在桌面应用自己的窗口里出现；改完当场生效，不用
重启、也不用把桌上那只关掉再打开。

**模型库多了两个分组。** **Venice AI**（它的无审查模型，含它转卖的 abliterated / uncensored 微调）
与**腾讯 TokenHub**（腾讯云的模型网关，收录腾讯自家的 Hy 对话模型）。TokenHub 和已有的混元直连是
两个服务，key 与控制台各自独立 —— 拿 TokenHub 的 key 请求混元直连端点会被拒，所以它自成一个分组。

**「被拒的原因，留在你按下去的地方」这一族收完了。** 概览页的 CEO 工位、侧栏的工位行、组织图的卡片
菜单、日历弹窗里那一条链接、机器卡上的 ssh 配置：五处打不开时，过去原因只落在一条六秒就走的通知里，
现在都留在你按下的那个东西旁边。组织图的卡片是定高的、画布又裁边，所以句子画在卡片脸上、按两行截断。

## 值得一提

- 通知只有「已读数」一项统计，没有送达回执、附件与链接跳转；范围也只有全体与单个账号两档。
- 通知有长度上限（标题 120 字、正文 2000 字），超了直接拒绝，不会被悄悄截短。
- 收件人打开收件箱的同一瞬间到达的通知不会被漏掉：那次「读」的答复当作基线，比它新的保留下来并计入未读。
- 桌宠形象是浏览器偏好（跟主题、字号一族），所以它跟着这个浏览器走，不写进桌面壳的配置里；缺值、乱填
  一律退回企鹅。
- TokenHub 的三条预置里只有 `hy4` 带价格；`hy4-flash` 与 `hy3` 故意不写 —— 腾讯自己的价格页读不到，
  写成 0 会被当成免费档。
- 装了外置主题的机器上，主题不再被应用自身的样式盖住；这条修复只动前端，装这一版即可。
- 机器卡上的拒绝句子画在卡片里、展开的详情之外，所以把卡片收起来也不会把它收走。

## 兼容

- 新增的数据库迁移只加两张表（通知与已读标记），前一代构建不读它们，回滚得住。
- 没有删除任何页面、路由或环境变量；通知只在桌面模式以外出现，既有接口形状没变。
- 数据根、配置文件格式、请求与响应都没有变化（通知是新增的表与路由；模型库只是多了两个分组）。
- 升级不需要做任何事。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。
- 「桌宠形象」这一行要装这一版的桌面端才看得见。
