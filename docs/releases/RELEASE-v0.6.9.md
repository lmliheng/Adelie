# Adelie v0.6.9 —— 文件面板能放 mp4 了，侧栏底部多了一份会话待做清单

这一版自 v0.6.8 起在 `main` 上落了 **6 个用户看得见的改动**（其余是每轮的记账与宣传片/文档）。
没有删除任何功能，数据根、配置格式与既有接口都没有变；升级不需要做任何事。

## 这一版的新东西

### 1. 文件面板里选中 mp4 就能直接播

以前文件面板只认图片、PDF、Word 和文本，点开一个 `.mp4` 只能下载。现在选中就地在面板里播放，
有播放、暂停和进度条；拖动进度条只取那一段，不会把文件从头读一遍。

为此服务端开始支持按字节区间返回文件（`Range` → `206`），mp4 也按 `video/mp4` 发出——以前发的是
`application/octet-stream`，带着 `nosniff` 的播放器会直接拒绝，所以过去即使把地址给播放器也放不出来。

**超过 50MB 的视频不在页面里预览**：服务端读一个文件的上限就是 50MB，超了会以 413 拒绝整份读取，
面板直接说明原因（「这个视频超过 50MB，不在页面里预览」），而不是挂一个放不出来的播放器。界面上限与
服务端一致，读不出来的时候也是这句话。只读的文件浏览器（不属于面板的那个）照旧不播：它没有播放器，
也没有能判断大小的文件列表。

### 2. 侧栏底部多了当前会话的待做清单

侧栏底部、用户行上面多了一个**待做**块，记当前这个会话还剩什么没做。行头是「还剩几条 / 一共几条」，
行尾的箭头收起或展开；勾选表示做完，可以删除，也可以在底部的输入框回车新增。换一个会话看到的就是
那一份，清单只跟着当前会话走。

这份清单不只是浏览器里的状态，而是这个会话 scratchpad 里的 `TODO.json`——界面和 Agent 读写的是同一个
文件：你在这里加的，Agent 下一轮就能看到；Agent 做事时补上的，那个回合结束就出现在这里。默认提示词里
也加了一条，让 Agent 手上有好几件事时把它们记在这儿。

写盘失败不会装作成功：那一次改动当场撤回并说明，点**重试**再发一次；读不出来时说另一句话。

### 3. 又有四处「被拒的原因只活六秒」搬到了发问的地方

- **更新弹窗自己发出的两个请求**（检查更新、发起更新）被拒时，原因留在弹窗里，弹窗不再关掉重开成
  「什么都没发生」的样子。
- **撤销一条忽略规则被拒**——原因留在按下去的那颗按钮旁边，规则本身还在原地。
- **存储台账页的三处失败**各自留在自己的位置上，五处写入不再一次说两遍。

### 4. 安全策略页的规则字段说出自己的长度上限

规则里的字符串字段写到上限时，页面直接说明这是上限，不必再试一次才知道自己写不进。

### 5. 服务端日志里一个请求只记一行

以前每个请求都出现两次（两层 HTTP 各记一次）：读日志得隔一行看一行，看着像页面请求了两遍，成对的两行
有时还互相打架。现在只由外层记一次，写客户端真正收到的状态——日志量减半，同样大小的轮转能覆盖两倍时间。

### 6. 首页与文档：中文变默认语言，加了一条 57 秒宣传片

README 的默认语言改成中文，首页嵌入一条由代码渲染出来的 57 秒宣传片，安装只保留一条路。macOS 桌面端
仍不随发布提供，系统需求按平台拆开写。

## 兼容

- 没有删除任何页面、路由或环境变量；没有新增环境变量。
- 数据根、配置文件格式、请求与响应都没有变化。
- 新文件面板只多了「视频」一种预览；服务端的 `Range` 支持是**增量**——不发 `Range` 的客户端拿到的
  与以前逐字节相同。
- 界面新增的只有侧栏底部的待做块、几处「原因」槽位；它们不动既有用法。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.9。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.6.8）把「被拒的原因留在原地」铺到最后一批页面，并让左下角菜单能看正在跑的会话和按天的
Token 账。文档在 <https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
