# Adelie v0.5.9 —— 主题能看见颜色再挑，异常能整条复制走，滚动不再被拽回底部

这一版自 v0.5.8 起在 `main` 上落了 **25 笔提交，其中 10 个用户看得见的改动**（其余是每轮的记账与
测试）。数据根、配置格式、包名与既有的请求接口都没有变化，装好的机器升级后不用改任何配置。

## 这一版改了什么

1. **外观页的主题改成一排卡片，每张画着它自己的颜色。** 以前挑主题是一行按钮，每个主题一个词：
   这台机器导入几个主题之后，这行要么折成一坨、要么横向滚动，而不管哪种，挑的都是看不见的名字 ——
   「白领」和「极客」差在哪儿，切过去才知道。现在每张卡片画着这个主题自己的底色、面板色、文字色和
   强调色，内置的与导入的分成两组。主题列表下面那一块也从一段说明改成「主题目录」加两个动作，路径
   与文件格式收进旁边的「?」。

2. **成本中心的异常表能把一整条异常复制走。** 每一行右端多一个复制按钮，复制出来是一段能独立成立
   的文字：时间、来源 · 错误码、类型，合行时还有条数与首次时间，随后是完整消息（换行照原样）。面板里
   被截掉的那部分 —— 402 的响应体、栈的头几行 —— 恰恰是排查时要的，现在可以整条粘到聊天里、贴进
   issue，或者交给另一个 Agent 看。

3. **异常表能按类型过滤，清空也只清看到的那一类。** 表格右上方多了一个「全部 / 未预期 / 预期内」的
   筛选，选一类之后表格、翻页和**清空**都只认这一类；清空的确认框会写明是哪一类、另一类保留，也确实
   只删这一类 —— 点了「清空」却把没显示在屏幕上的另一类一起带走，正是确认框要防的事。

4. **回复流式输出时向上滚，视图不再被拽回底部。** 从对话底部用滚轮向上滚，以前常常紧跟着弹回一小段；
   现在向上滚轮的第一格就停止跟随底部，直到自己滚回底部才恢复。

5. **底部停靠栏拉到最大时不再盖住输入区。** 此前它最高可占对话列的 85%，多数窗口里输入区被压到
   停靠栏下面、点不到；现在停靠状态的最大高度给输入区留出完整高度，并在其上留一条消息带。

6. **停靠面板只属于屏幕上那个 Session。** 切换对话之后的几条自动路径以前会操作刚切过去的对话：
   子智能体面板在从未派生过子会话的会话里打开、下一个对话的面板执行上一个对话点过的文件链接、
   答复得晚的标签关闭关掉别处的面板、首次发送完成后把用户拽回上一个 Session。现在都落在各自的
   作用域里。

7. **保存或删除快捷指令被服务端拒绝时，框留着、写过的内容也留着。** 以前保存一按就收框，被拒之后
   刚写下的名称与 Prompt 一起消失，只剩一条自己会走的提示；删除也一样。现在两处都等到写入落地才
   收框，被拒时那句话画在框里，原样保留字段，重试还是同一个按钮。

8. **在局域网地址上打开 Web App 时，连接 TokenDance 改为直接走粘贴授权码。** 授权页只接受跳回
   HTTPS 或回环地址，以前在 `http://192.168.x.x:4000` 这种地址上会撞上「授权请求无效」；现在服务端
   只在地址能接收跳转时才请求跳回，否则直接以手动模式打开，弹窗进入填写一次性授权码这一步。

9. **模型库的 TokenDance 分组多出四条模型，价格按卖家当下的目录重核。** DeepSeek V4.1 Flash 1017、
   DeepSeek V4 Pro Preview、Kimi K3.1 Pro、GLM-5.3 FlashX；这一组全部 18 条的价格、上下文窗口与
   促销都重核过（上次核对是 2026-09-16）。已有项目点一次**同步预置**就拿到。

10. **版权信息页的「来源」指向字体项目本身。** 以前写的是 `@fontsource-variable/mona-sans` 这样的
    包名，既不是网址也不是许可的持有人；现在那一行链到字体自己的项目，文件从哪个 npm 包来另起一行
    「打包来源」。

## 兼容

- 只多了两个字段与一条 UI 约定：TokenDance 授权发起接口的返回多了 `mode`（说明流程以自动跳转还是
  手动粘贴打开），主题的一侧多了「导入主题只写了一部分取值」的说明行。既有的请求、响应与磁盘格式
  都没有变。
- 新装的机器与升级的机器都不需要改配置；数据根一个字节没动。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上 26 个包都到了 0.5.9。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.5.8）让更新拉不到 GitHub 时可以由 Adelie 接手排查并下载，并让插件更新不再被「目录正被
占用」拖死。文档在 <https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
