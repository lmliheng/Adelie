# Adelie v0.7.0 —— 桌宠能打电话了，安卓端的第一颗包也出来了

v0.7.0 是两个「端」的一版。桌面上的小企鹅多了一条语音通话：点一下「打电话」，窗口展开成通话界面，
之后整段对话是用嘴说的 —— 模型的声音边生成边播、它说的话跟着声音逐句上屏，你说的话被实时转写；
说到一半想插话，正在播的那句立刻断掉，这一轮记成「被打断」而不是「说完了」。挂断，窗口收回原样。

另一个端是安卓：可以直接侧载的 APK 第一次成包（自带运行时，引擎全在手机上跑，不连任何服务器），
进入内测；那颗包的工程源码随之收进了仓库。除此之外是两条修复与三处老问题的收尾：从别的机器搬过来
的会话不再因为工作区不在本机而发不出消息，连通性测试也不再把密钥里混进的一个字符说成网络故障。

## 安装

**已经装过的人**：桌面端在应用内更新（账号菜单的更新入口，或应用菜单里的「检查更新」）；命令行与
Web 用 `penguin update`，或重装 `npm install -g @adelie/cli` —— 两者都需要 Node >= 24。npm 上的包都
到了 0.7.0。Windows 安装包仍未签名，SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**全新的机器**，单行脚本：

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

## 亮点

**桌宠能打电话了。** 通话是一条中继：浏览器只开一条 WebSocket，服务端再开一条到服务商，密钥加在
服务端这一跳上，页面从头到尾拿不到它。会话该长什么样（人设、音色、音频格式）由服务端在上游连上的
那一刻下发，所以这块窗口走到哪里都是同一个脾气。四个字段在「设置 › 服务器 › 实时语音」里一起写：
站点、模型、音色、密钥；密钥只写不回读，旁边那颗「测试连通性」按页面上当前的值真握手一次。没存
密钥时，桌宠那一行直接写明「还没配置」，不用点了才失败。

**安卓端的 Adelie 第一次成包。** bionic 版 Node 24、Adelie 本体与自己的前端打在一个 APK 里，装上去
不需要 Termux、也不需要 proot；引擎全在手机上，不连任何服务器。它只出 arm64 与 x86_64，没有
`node-pty`，沙箱退化为直接执行；不进应用商店、也没有签名，安装时系统会提示「来自未知来源」。这一版
是内测包，工程源码（Gradle 工程 + 四支打包脚本 + 图标与截图）已经收进仓库的 `android/`。

**被拒的原因，留在你按下去的地方 —— 这一族又收尾三处。** 成员弹层里「打开工位会话」失败时，原因
过去只落在一条盖在弹层上的通知里；现在句子留在问它的那一行下面，弹层仍站着，那一行的按钮就是重试。
插件导入的弹窗里，选中的 zip 读不出来或超过 14 MB 时同样是那个位置。文件树里重试一个读不出来的
目录，它下面仍开着的子目录会跟着重列一遍 —— 在此之前它们会带着失败之前读到的旧内容回来。

**两处不再甩英文原文。** 连通性测试遇到密钥里混进中文、全角标点或看不见的字符时（请求头只装得下
Latin-1），过去递出来的是一句 `Cannot convert argument to a ByteString…`，读者会去查网络；现在说的是
哪个字段、怎么改。从别的安装导入进来的会话，工作区按两种判法处理：自动建的临时工作区在本机按相同
名字重建，你自己指过的目录则要求它仍在这台机器上 —— 它不在时恢复照旧失败，只是理由换成了界面里
已有的那句中文。

## 值得一提

- 通话的中断是真中断：你说的第一句一到，正在播的那句音频立刻清空、回复自己那份进度也一起丢掉，
  这一轮记成「被打断」，而不是一次说完的回复。
- 模型写进连接的查询串里，所以**通话中途换不了模型**：要换重新拨一次号。
- 麦克风电平在进状态之前先量化到 0.1，宠物页不会因为一秒几十次的重画而忙起来。
- 成员弹层关掉时，那一行的拒绝句子一起带走。
- 插件导入的确认按钮按不下去、选择行不写文件名时，原因就写在选择文件那一行下面。
- 重试失败的目录时，某个后代再失败也照旧把原因留在它自己那一行下面。
- 安卓端这一版是内测：只出 arm64 与 x86_64，没有 `node-pty`，沙箱退化为直接执行，未上架商店。
- 从另一台机器导入的 Trace，其会话的临时工作区会在本机重建；用户指定的目录不会被凭空创建。

## 兼容

- 没有删除任何页面、路由或环境变量；实时语音新增的几个键都可选、默认为空，不配就等于没有这个功能。
- 数据根、配置文件格式、请求与响应都没有变化（实时语音是新增字段，读写旧版本不受影响）。
- 导入的会话要接着发消息，临时工作区在本机重建、用户选的目录必须仍在；别的恢复判据没变。
- 升级不需要做任何事。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。
- 桌宠的通话界面要装这一版的桌面端才看得见（旧版桌面端上没有那一行）；安卓端要装这一版的内测包。

上一版（v0.6.12）把「被拒的原因」这一族收在了对话框与输入卡上，并让频道里实时到达的消息按自己的
日文件归日。文档在 <https://lmliheng.github.io/Adelie/docs/>。本版全文见
[`docs/releases/RELEASE-v0.7.0.md`](https://github.com/lmliheng/Adelie/blob/main/docs/releases/RELEASE-v0.7.0.md)。
