# Adelie v0.6.10 —— 「被拒的原因」这一族收尾，网络吞掉实时流时二十秒就自己刷新

这一版自 v0.6.9 起在 `main` 上落了 **约二十个用户看得见的改动**（其余是每轮的记账、文档与宣传片）。
没有删除任何页面、路由或环境变量，数据根与配置格式都没有变；升级不需要做任何事。

## 这一版的新东西

### 1. 「被拒的原因」这一族收尾：最后十三处也留在原地

前几版一直在做同一件事：按下按钮、服务器拒绝、界面却装作什么都没发生——按钮弹回去，什么也没说。
这一版把剩下的十三处做完，原因都写在**按下去的那个地方旁边**，措辞用界面自己的说法：

- **撤回**一条还在排队、没发出去的消息被拒 → 原因留在那一行下面，消息仍在队列里，可以再按一次。
- **转入后台执行**被拒 → 原因留在那张卡片的那一行下面。
- 在**已经有内容的对话**里发不出去的消息 → 原因留在输入卡上方。
- **`/agent` 交接**没能开出新对话 → 原因留在输入卡上方，草稿还在原处。
- **`/model` 换模型**被拒 → 原因留在输入卡上方。
- **`/compact` 压缩**没能开始 → 原因留在输入卡上方。
- 回复里图片的**拆图层**没能发出 → 原因留在图片动作栏下面。
- **「压缩后切换」**没能开始 → 确认框留着，原因写在框里，而不是关掉重开成没发生过的样子。
- **审批决定**被拒 → 原因留在仍在发问的那个块里。
- API 标签页**「试一试」里的审批决定与停止**被拒 → 原因留在那一行、那颗仍是重试的按钮下面。
- **会话里的停止**没被服务器接下 → 原因留在输入卡上方，同一颗停止按钮留着可以再按。

### 2. 网络把实时流吞掉时，约二十秒就自己刷新

有些网络（网吧、透明代理）会把长连接的响应体扣住：连接看着是通的，帧却一个都不到，界面上永远停在
上一个状态。现在首帧超过 10 秒、或者连着两次静默，就判定断开并改成每 6 秒取一次，对话框上方写一句
「实时连接已断开，正在定时刷新」——**约二十秒**就开始自己恢复，不必刷新页面。此前这条判定要等到
九十秒上下。

### 3. 输入框打 `/` 弹出的那个菜单，长说明不再被截掉

面板加宽了，说明可以换到两行排完，命令名过长时自己省略而不是把说明挤没；被截的说明以前要靠悬停看全，
而悬停浮层正好压住下面几行候选。

### 4. 账号菜单的「正在运行」不会再漏掉真在跑的会话

以前有一类网络下，菜单会写着「没有正在运行的会话」，而对话就在跑。原因是它把「打开菜单时问的那一次」
和「频道推来的状态」合并时无条件让后者覆盖前者：频道是唯一会报告「运行结束」的来源，所以它必然留着
一条旧的「已结束」；一旦中间设备把流扣住，下一次运行的「运行中」送不到，那次查询的结果就被这条旧状态
盖掉、再被当成「已经结束」滤掉。现在只有**相对这次查询动过**的状态才能改写一行。

### 5. 模型的思考也用你的语言（默认提示词）

默认系统提示词原来只要求「用用户的语言**回复**」，于是中文对话里，思考过程（界面上你看得到的那块）
仍是用英文写的。现在要求思考也用同一种语言。这是一句提示词，不是开关：模型有多听话各不相同，它能
减少英文思考，不保证清零。已经改过提示词的 Agent 不受影响，没改过的会在装载时前进到新默认。

### 6. 站点与文档的小改

文档页的根 `lang` 跟着界面语言走（读屏与翻译工具的语气不再对不上）；README 首屏换成一条能直接播放的
宣传片（开头九秒的循环 GIF，GitHub 会删掉 README 里的 video 标签，所以另存了一份）。

## 兼容

- 没有删除任何页面、路由或环境变量；没有新增环境变量。
- 数据根、配置文件格式、请求与响应都没有变化。
- 会话的实时刷新只是**更早**判定断开（原来九十秒上下，现在约二十秒），帧照旧直接送达。
- 账号菜单的「正在运行」只是修好漏掉会话的那一种情形，列表本身没有换。
- 默认提示词变了，内核版本前进到 `2026-11-18`：没被改过的提示词会跟着前进，你改过的整块保留，
  想回到默认随时可恢复。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.10。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
