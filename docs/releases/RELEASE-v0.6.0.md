# Adelie v0.6.0 —— 图片点开后有能真的做事的工具条，模型分组的密钥可以直接从自己的密钥里分配

这一版自 v0.5.10 起在 `main` 上落了 **11 笔提交，其中 5 个用户看得见的改动**（其余是每轮的记账与
测试）。数据根、配置格式、包名与既有的请求接口都没有变化，装好的机器升级后不用改任何配置。

从这一版起版本号按「有功能就进一位」走，所以是 0.6.0 而不是 0.5.11。

## 这一版改了什么

1. **点开一张图，图下有了一条真的能用的工具条。** 以前图片放大后只有一件事可做：关掉。现在图片下面
   是一条胶囊工具条，只放页面**真做得到**的事 —— 把这张图存下来，以及这批图一起打开时在它们之间
   前后翻（一批五张图里点开一张，就能在另外四张之间翻，不用关掉再去找下一个缩略图）。图片自己的像素
   尺寸写在框角上，所以一张 2364 × 1773 的截图会这么说自己，而不是看上去只有窗口那么大。编辑、拆
   图层、去背景那一族是图像生成服务的活，这里没有接口撑着它们，于是那条条上一个这样的按钮都没有。
   比角标还小的图（40 × 30 的图标）上，角标不再糊住图片：图片本来放不下两个角标时，尺寸挪到图片
   左边、关闭按钮挪到右边，仍在同一行、仍在遮罩之上，谁也不压着谁。

2. **回复里的图片点开后多了两个动作，按下就让 Agent 动手。** 以前想拿一张刚生成的图再生成点什么都
   得回输入框里手打一遍那张图的路径。现在放大层的工具条上多出 **拆图层** 与 **照这张改一版**，图片
   自己的路径由界面填好。两个动作都不走 App 自己的接口 —— 这一仓没有图像端点，模型、密钥和文件都在
   Agent 那一侧，所以动作其实是**交给 Agent 的一句话**：拆图层是一次参数确定的 Seedream 调用，点了
   就直接作为你的消息发出去，回复里有底图和每一层透明 PNG；「照这张改一版」改成什么样得由你说，所以
   它只把带参考图的指令填进输入框，按发送仍是你的决定 —— 生成按张计费，不该由一次点击替你买单。
   Agent 没装出图技能（`@adelie/use-seedream`）时两个按钮都不出现。

3. **模型分组的 key 可以直接从自己的密钥里分配。** 模型分组头部多了一个「从用户密钥分配」：勾一条
   左下角账号菜单里存的全局密钥，一次性拷到该分组下全部模型当 API key。以前给一组模型换 key，得先去
   别处把密钥翻出来复制一遍再贴回来。它和「分配用户密钥给 Agent」是同一种操作：**拷贝，不是引用** ——
   之后改全局那一条，要重新分配才会同步；拷贝完就归这个项目，两个成员之间不再有「用谁的 key」这个
   问题。浏览器永远看不到明文（用户密钥的响应一直是打码的），所以请求只带键名，由服务端把值读出来
   直接写进项目的 `.project_config.toml`。custom 分组每一行各连自己的端点，写一个 key 过去必然错，
   所以不给这个动作。

4. **同步预置补上的模型直接沿用分组里已有的 key，不再显示「未配置密钥」。** 网关分组（TokenDance、
   OpenRouter、Fireworks AI、SiliconFlow、两个 Qwen 网关、ModelScope）里所有条目都由同一个端点、
   同一个登录来应答，所以缺 key 的预置会显示成没配密钥，在一排能用的条目旁边连自己的测速都过不了，
   唯一的办法是把同一把 key 再粘一遍。现在保存模型表时，这样的条目会直接沿用分组里已经有的那把 key
   —— 一次粘贴就能把整组配好。借的条件很窄：**同一个分组、同一个 base URL** 下唯一的 `api_key`；
   同一分组里有两把不同的 key（两个账号，或有意的拆分）就留空，不替你猜一个。明确要求清除的条目也
   不会被旁边的条目填回来。key 不离开服务端，沿用只写进 `.project_config.toml`。

## 兼容

- 只多了一条请求（`POST /api/projects/:p/models/assign-user-key`）与模型页分组头部的一个动作，
  加两处 UI 约定（图片放大层的工具条与两个动作按钮）。既有的请求、响应与磁盘格式都没有变。
- 新装的机器与升级的机器都不需要改配置；数据根一个字节没动。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.0。

**主题库**：`@lmliheng/adelie-themes` 1.3.0 把目录收到四套 —— 赛博朋克、手绘涂鸦、陶光、拟物化。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.5.10）让文件面板能直接读 Word 与 PDF、外观页多了装主题的地方。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
