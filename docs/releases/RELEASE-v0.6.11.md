# Adelie v0.6.11 —— 把窗口拉窄再拉宽，你在各个面板里的位置都还在

这一版自 v0.6.10 起落了 **十一个修复**，几乎都围绕同一件小事：窗口跨过窄屏与桌面之间那条线时，
右侧那排停靠面板会换一个地方重新挂载，原来记在面板里的去处就跟着没了——看到一半的文件、
挑好的一条记忆、展开着的几轮轨迹、打到一半的字。现在这些位置跟着你走。

没有删除任何页面、路由或环境变量；数据根、配置格式与请求响应都没有变；升级不需要做任何事。

## 这一版的新东西

### 1. 文件、记忆、轨迹三个面板，换布局后还在原处

窗口跨过断点（桌面右侧栏 ↔ 窄屏合并面）时，同一个标签页会在另一侧重新长出来。此前它一律从头
开始：文件面板回到树根、展开的目录合上；记忆面板从「正在读的那条」退回列表、两处滚动都回到顶上；
轨迹面板关掉你展开的轮次——实测开着第 1 轮、滚到 320 像素处，拉宽后变成开着第 3 轮、从头开始。

现在每个面板按对话记一处「上次停在哪」，只在**新挂载落在另一侧**时交回去：

- **文件面板**：打开的文件、展开的目录、面包屑所指的目录。
- **记忆面板**：你在列表还是在读某一条，以及列表与正文各自的滚动位置。
- **轨迹面板**：你展开了哪几轮、滚到文件的哪里，以及压缩过的会话里你选了哪一份分片（默认仍是最新那份）。

换一个会话、或者关掉标签页再打开，照旧从开头开始——那不是在搬动面板，是换了个东西在看。

### 2. 换布局不再把你关掉的东西又打开一遍

页面交给停靠面板的每条命令都是「按一下」。面板体在跨断点时整份重建，它记着「这条已经执行过」的
账跟着旧的那份一起没了，于是新的挂载又执行一遍：文件面板把你已经关掉、已经离开的文件重新打开，
记忆面板把你已经退出来的那条记忆又拽回来。现在这份账活得比重新挂载长、仍随标签页一起消失。

### 3. 子 Agent 面板：没发出去的字、说明过的原因、暂存的引用都留在原地

在子 Agent 自己的对话里做到一半跨一次断点，此前输入框里的一切都会消失，而那个子会话一直在跑：

- 打到一半的字，以及钉住的思考等级；
- 「这次停止没成功」「这个等级没钉住」那两句原因；
- 在对话里选中一段、点「添加到对话」暂存下来的引用。

这些现在按子会话记着，跨回来原样还在。暂存的引用只在内存里跟着这一份对话走，不从草稿缓存里恢复
——十分钟前引用的那段文件可能已经变了。

### 4. 子 Agent 的「停止」被拒时，说清楚是哪一个还在跑

以前面板里按停止，服务器出错也一声不吭：子会话照旧在跑、按钮照旧，屏幕上连一条会自己消失的
通知都没有。现在原因写在那颗按钮上方的输入框上，点名是哪一个运行还在继续，并且跟这次运行同生
同死——子会话一回到空闲，这句话就收走。

### 5. 自建分组没填服务地址时，立刻告诉你缺的是地址

vLLM、Custom 与用户自建的分组都不预设服务地址，地址写在每条模型条目上。只填了 key、地址留空时，
探针没有地址可去，就用了协议自己的默认端点（OpenAI 协议下是 `api.openai.com`），在那里把 20 秒
超时跑满，最后回一句英文的原始网络错误——你只看到「连接错误」，看不出真正缺的是地址。现在在拨号
之前就认出这件事，对话框用自己的话说明白。厂商分组、网关、以及条目上本来就写了地址的分组照旧
直接拨号。

## 兼容

- 没有删除任何页面、路由或环境变量；没有新增环境变量。
- 数据根、配置文件格式、请求与响应都没有变化。
- 面板位置只活在当前这个页面里：换会话、关标签页、刷新都会从头开始，也不会写进磁盘。
- 「停止被拒」只是把原来吞掉的失败显示出来，停止的行为没有变。
- 「缺地址」只在确实四处都没有地址时才报，原来能连上的分组不受影响。

## 升级

**桌面端**在应用内更新：账号菜单的更新入口，或者应用菜单里的「检查更新」。Windows 安装包仍未签名，
SmartScreen 会提示一次（「更多信息 → 仍要运行」）。

**命令行与 Web**：`penguin update`（或重装 `npm install -g @adelie/cli`）。npm 上的包都到了 0.6.11。

## 安装

```bash
curl -fsSL https://github.com/lmliheng/Adelie/releases/latest/download/install.sh | sh
```

```powershell
irm https://github.com/lmliheng/Adelie/releases/latest/download/install.ps1 | iex
```

也可以只装 CLI：`npm install -g @adelie/cli`（需要 Node.js >= 24）。

## 要求

- Node.js >= 24（单行安装脚本自带运行时，npm 安装需要本机有）。
- Linux / macOS / Windows 的 x64 与 arm64；其他 POSIX 平台用 `--universal` 安装包。
- 桌面端：Linux 提供 AppImage 与 deb，Windows 提供 exe；macOS 未签名，这一版不随 Release 发布。

上一版（v0.6.10）收尾了「被拒的原因」这一族，并让被网络扣住的实时流约二十秒就自己恢复。文档在
<https://lmliheng.github.io/Adelie/docs/>。变更明细见仓库里的
[`CHANGELOG.zh.md`](https://github.com/lmliheng/Adelie/blob/main/CHANGELOG.zh.md)。
