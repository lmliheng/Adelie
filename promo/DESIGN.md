# Adelie 宣传片 · 设计说明

1920×1080 / 30fps / 1800 帧 / 60.0s，全部由 React 组件画出来，没有一帧来自截图或素材库。
这份文档解释**为什么这么拍**：叙事、色板、构图、动效，以及每条事实的出处。

---

## 1. 这条片子要说什么

一句话：**Adelie 的智能体是一段文字；改这段文字，就是它进化。**

顺序是按「一个人被说服的过程」排的，不是按功能列表排的：

1. 先让他认出图标（`open`）；
2. 再划掉他心里那句话——「AI 只会聊天」（`thesis`）；
3. 让他看见一个智能体**由一段文件长出来**（`text`）——这是全片的论点；
4. 让它跑一次真任务，工具调用一条条长出来（`demo`）；
5. 它还有别的能力：插件、子代理、定时、记忆（`skills`）；
6. **它给自己打分，然后改那段文字**（`evolve`）——论点的第二半；
7. 每一步都记账（`cost`）；
8. 文件和密钥不出这台机器（`local`）；
9. 名字 + 一句话 + 仓库地址（`close`）。

第 3 场和第 6 场是全片的重心，其余六场是它周围的证据。

`src/Promo.tsx` 的 `SCENES` 是唯一的时钟；`Root.tsx` 的 `durationInFrames` 从它来。

| # | 场景 | 帧 | 时长 | 讲什么 |
| --- | --- | --- | --- | --- |
| 1 | `open` | 0–120 | 4s | 图标落位、轨道画出、字标收拢 |
| 2 | `thesis` | 120–270 | 5s | 划掉「只会聊天」，换成「写一段话」；右侧给出一段真的 AGENTS.md |
| 3 | `text` | 270–570 | 10s | 左边逐行写出 AGENTS.md，右边长出一个智能体 |
| 4 | `demo` | 570–840 | 9s | 一句话、六步工具调用、产出 docx |

## 3. 视觉语言：两个色板，不许混

这条片子里有两种颜色，它们的来源不同，**混用就会垮**。

### 3.1 片子自己的色板（`theme.ts` 的 `C`）

取自第一版成片的实帧，不是凭感觉挑的：直接在 1920×1080 的帧上取像素。

| 用途 | 值 | 依据 |
| --- | --- | --- |
| 画布 | `#000000` | v1 实帧四角全黑 |
| 卡片 / 面板 | `#0d0d0d` | v1 卡片实采样 `rgb(13,13,13)` |
| 细线 | `#1f1f1f` | 上一层 |
| 正文 | `#f2f3f5` | 近白 |
| 次要 / 更次要 | `#9b9ea3` / `#6b6e73` | 暗底上的两级灰 |
| 强调蓝（文字） | `#4a8cff` | v1「动手」二字实测 `rgb(71,142,255)` |
| 图标轨道蓝 | `#0258ee` | 图标本身 |
| 辉光 | `rgba(0,15,41,1)` | v1 中心实测峰值 `rgb(0,15,41)`，到 x≈240 / x≈1680 处归零 |

背景由 `Backdrop.tsx` 一次画出、挂在所有场景之外：纯黑 + 一枚 1080×620 的藏青椭圆辉光
（随帧极慢漂移几像素）+ 4% 的 24px 点阵。**纯黑是刻意的**：黑底有纵深，白底没有。

### 3.2 应用自己的色板（`theme.ts` 的 `UI`）

第 4 场那个窗口里的颜色一个都不是发明的，全部抄自
`packages/ui/src/themes/github.css` 的 `.dark` 规则：

| 用途 | 值 |
| --- | --- |
| canvas | `#121212` |
| surface / surface-muted | `#1a1a1a` / `#202020` |
| line | `#262626`（强调 `#333333`） |
| 正文 / 强调 | `#d6d6d6` / `#f0f0f0` |
| 次要 / 更次要 | `#a1a1a1` / `#8a8a8a` |
| 链接 | `#8ab4f8` |

依据：`packages/ui/src/boot.ts` 在 `<html>` 上按 `prefers-color-scheme` 加 `.dark`，所以
**深色就是真界面**，不是「为了黑而黑」。窗口是深色的，片子的画布是更黑的，两者因此分得开。

> 规则：界面里只用 `UI`，片子里只用 `C`。不要给界面加品牌蓝，也不要把品牌蓝调成界面灰。

### 3.3 图标

`BrandMark.tsx` 按图标本体画：白色圆角牌、藏青企鹅、白眼球、蓝喙、`#0258ee` 的轨道环。
牌面必须是白的——它是图标，不是界面。

## 4. 构图

- **安全边 64px。** 内容顶到离边 64 的位置，四边不留大片空。中间漂浮的版式会让 1080p 显得空。
- **每场至少有一条边出血**：`open` 底部细线、`text` 的编辑器、`skills` 的两列卡片、`local` 的外框。
- **一场只用一个主视觉**：一段文字（`text`）、一个窗口（`demo`）、一张账单（`cost`）。
- **字号的阶梯**：主张 108px / 104px（`thesis`）、场标题 62px、面板标题 29–60px、
  正文 22–27px、单号/路径 15–19px。没有 14px 以下的字。

## 5. 动效与转场

- **一套缓动**（`motion.ts`）：弹簧 `damping 200 / stiffness 110 / mass 0.6`，加 `Easing.out(cubic)`。
- **切点是切点**：`sceneOpacity` 用 5 帧把场景从 55% 拉到 100%，不做交叉淡化，也不压黑。
  试过 10 帧叠加，两套版式会互相穿帮（重影），比黑一下更难看。
- **`rise()` 预跑 6 帧**：弹簧在场景第 0 帧之前就先走一段，所以切进来时版式已经是成型的，
  不会出现「空画面上半成品」。
- **每场一次极慢推近**（`push`，1 → 1.012），这是全片唯一的镜头运动。
- **数字会动**（`roll`）：分数、金额、耗时都是滚上去的，静止的数字像截图。

## 6. 事实依据

片子里每一处声称都要能在仓库里找到对应：

| 画面 | 依据 |
| --- | --- |
| `AGENTS.md` 是智能体配置，每次会话重新读取 | `packages/*/agent_state/AGENTS.md`、`loadAgentState` |
| SKILL.md 即技能 | `agent_state/skills/*/SKILL.md` |
| 子代理、定时任务、长期记忆 | 引擎与 `agent_state/schedule/`、`memory/` |
| 成本中心逐次记账 | 界面「成本中心」与 `llm_usage` 记账 |
| 深色界面配色 | `packages/ui/src/themes/github.css` `.dark` |
| 模型随你换、1000+ 兼容 OpenAI 协议的端点 | 模型库与内置供应商 |
| 文件/密钥在本机 | `~/.adelie/data`、`agent_state/.vault.toml` |

演示与评估中的**具体数字**（34s、6 步、$0.068、62/78/91）是示意值，`cost` 场画面上已经写明
「数字是示意，账单的形状是真的」。

## 7. 三版是怎么变的

| | v1（57s） | v2（60s，被否） | v3（60s，当前） |
| --- | --- | --- | --- |
| 画布 | 纯黑 + 中心辉光 | 白纸 + 32px 网格 + 边缘文字 | 纯黑 + 藏青椭圆辉光 + 点阵 |
| 界面 | 浅色窗口浮在黑底上 | 白底铺满、贴边 | **深色真主题**窗口浮在黑底上 |
| 字号 | 大字，居中 | 编辑排版，14–25px 偏多 | 大字，左对齐顶到右边 |
| 核心论点 | 没讲清 | 有，但埋在文档样式里 | 第 3、6 场各占 10s / 9s |
| 转场 | 硬切 | 交叉淡化（压黑） | 快切，预跑弹簧 |

v2 的错在于**把「主题色不对」理解成「换成应用的浅色默认主题」**：于是黑底电影感变成白底文档感，
四周的细线与角标让人读成 PPT。v3 的做法是——片子保持黑，界面保持诚实（用应用真实的深色主题），
两者靠亮度和色相分开。

改动只发生在设计层：时间线、文案、九场顺序都没变。
