# 宣传片交接：给 Adelie Desktop

> 结论先行：这条片子**只能由拿到真实桌面端的人做**。我已经把界面基准（真实截图 + 实测 token
> + 尺寸）和分镜稿全部整理在这里，桌面端照着拍／照着复刻，不要再手画界面。

## 0. 要求一句话

重做 60 秒宣传片：黑底电影感的画布（这部分已经定稿，见 §5），**但画面里所有界面必须来自真实
运行的 Adelie Desktop**——真实录屏、真实截图，或直接用 `@adelie/ui` 的组件渲染；不许手画近似。

## 1. 为什么交出去

前三版我都做失败了，原因不同：

| 版本 | 问题 |
| --- | --- |
| v1（57s） | 纯黑底、大字，观感对；但**没讲清应用核心**（智能体 = 一段文字） |
| v2（60s） | 把「主题色不对」理解成「换成浅色主题」，白纸 + 细线 → 像 PPT |
| v3（60s，当前仓库里） | 画面语言修对了（黑底 + 辉光 + 大字 + 窗口浮起），**但界面是我手画的**，和桌面端实际长得差太远 |

v3 的手画界面与真实的差异（这一组就是「不符合 desktop 实际样子」）：

| 我手画的 | 真实桌面端 |

## 4. 取真实画面的三种做法（按优先级）

**A. 真实录屏（首选，第 3、4、5、6、7、8 场）**

- 用 Playwright 以 1440×900、`deviceScaleFactor: 2` 驱动桌面端/Web 端，`ffmpeg` 录同一路；
  或 Electron 壳内直接抓帧。
- 录下来的素材再裁切缩放：**缩放不要小于 0.75**（1.0 最清晰），裁窗口圆角 12–16px、加一层长阴影。
- 鼠标指针自绘（14px 白色圆点 + 轻微拖影），系统指针必须关掉。
- 画面里不要出现：初始密码提示条、测试会话名、真实密钥路径以外的敏感信息。

**B. 组件级复刻（第 5 场的卡片、任何需要「生长」动作的地方）**

- 直接 `import { ... } from '@adelie/ui'` 在 Remotion 里渲染真组件，字体与 token 自动一致。
- 只有在真组件拿不到（例如需要注入假数据）时才允许降级到 C，且必须在注释里写明原因。

**C. 静帧合成（兜底）**

- 用 §2 的截图裁切、缩放、做视差；动效只允许「整体推近、淡入、高亮框」三类。
- **不允许**在截图上画任何原本不存在的元素（按钮、函数名、耗时数字）。

## 5. 已经定稿、不用再讨论的部分

这部分是 v3 改对、并被明确认可的方向（黑底电影感），桌面端直接沿用：

- **画布**：纯黑 `#000000` + 一枚 1080×620 的藏青椭圆辉光（峰值 `rgba(0,15,41,1)`，到 x≈240/1680
  归零）+ 4% 的 24px 点阵。
- **两组色板不许混**：片子自己的 `C`（`#0d0d0d` 面板、`#1f1f1f` 细线、`#f2f3f5` 正文、
  `#4a8cff` 强调、`#0258ee` 轨道蓝）与界面的 `UI`（§2 的 token）。界面里不加品牌蓝，片子里不刷界面灰。
- **构图**：安全边 64px，每场至少一条边出血；字号台阶 62–132px，不写 14px 以下的字。
- **转场**：5 帧快切 + 元素预跑（弹簧提前 6 帧），不要交叉淡化（两套版式会重影），不要压黑。
- **事实**：`AGENTS.md`、`SKILL.md`、`agent_state/`、成本记账、模型可换、密钥在本机——每条都要能在仓库找到依据。

## 6. 已知的坑

- **这台机器的 Chromium 软渲染每 3–5 分钟崩一次**（渲染器进程消失、node 端一直等、不报错）。
  整片一次渲不完：按 150 帧分段、每段新开浏览器，崩了重试，最后用图片序列拼回 1800 帧
  （见 `render-chunks.sh`，脚本就是这么写的）。
- 直接 `-c copy` 拼各段会多出重复帧（每段容器时长有 1–2 帧误差），必须走图片序列。
- `git fetch` 在这台机器会挂死；推仓库走 GitHub Git Data API（`$GITHUB_PAT`）。
- 页面里的 Web 服务对 `Host` 敏感：用 `localhost` 不用 `127.0.0.1`，否则 API 报
  `The API is not served on the preview host.`。

## 7. 交付与验收

**交付**：`out/adelie-promo.mp4`（1920×1080 / 30fps / 60.000s / 1800 帧）+ 一张封面 png +
出片工程（Remotion 或等价）+ `海报` 一版竖版 1080×1920（可选）。

**验收清单**（逐条打勾才算完）：

1. 每一处界面元素都能在 §2 的截图里找到对应；没有手画的近似元素；
2. 侧栏顺序、图标、选中态、底部用户条与真实一致；
3. 首页 Hero（图标 144 / 标语 / 版本号）与真实一致；
4. 成本场用的是「成本与统计」页，不是虚构账单；
5. 60.000s、1800 帧、四边不留大片空；
6. 切点无黑帧、无重影；
7. 界面窗口在画布上浮起（圆角 12–16 + 长阴影），不是贴边平铺。
