**服务器浏览器**是 Web App 里的一个页面（侧栏的**服务器浏览器**）：浏览器进程跑在服务端那台机器上，你在这个页面里看它的画面，也在它上面点击、滚动和打字。

它是给[内置浏览器](/builtin-browser)够不着的场合用的。内置浏览器的页面是桌面应用窗口里的元素，所以只有在桌面应用里才有；用浏览器打开 `penguin web`、Docker、或者一台被远程访问的机器，都没有它。服务器浏览器正好相反：它只要求服务器上装了一个 Chromium 或 Chrome。

- 想看它是什么、什么时候用它，见[什么时候用它](#什么时候用它)。
- 想开一个页面、点里面的东西，见[使用](#使用)。
- 服务器上没装浏览器、或者不想让它跑，见[关闭或另指一个浏览器](#关闭或另指一个浏览器)。
- Agent 自己驱动浏览器是另一件事，见[内置浏览器](/builtin-browser#在命令行中驱动)。

## 什么时候用它

它是整机唯一的一组浏览页面，只属于服务器本身：每个 Project、每个对话看到的都是同一个浏览器和它那一个页面。这与内置浏览器不同，后者的标签页同样是整机共享的，但那个浏览器长在桌面应用的窗口里。

用途通常是「这台机器上的浏览器看到的，和我的机器不一样」：

- 在一台内网或限制访问的服务器上打开只有那里能访问的页面。
- 在没有图形界面的机器上，用它来看一个网页长什么样——服务器会给浏览器一个虚拟显示器，所以它是个正常的窗口浏览器，不是无头模式。
- 把它当成一个「别人帮我盯着这个页面」的窗口，比如一个需要一直开着、又不值得占用自己屏幕的看板。

**它是管理员的工具。** 启动它会在服务器上拉起一个进程，它用的浏览器配置也是整机共用的，所以这个页面和它背后的每一条路由都只对管理员开放。

## 使用

打开侧栏的**服务器浏览器**就会开始解冻：页面里的画面请求送达时，服务器就把浏览器拉起来（不需要你先按一次启动）。工具栏从左到右是**后退**、**前进**、**刷新**、地址栏和**打开**；最右边是在浏览器不运行时**启动**它、运行中**停止**它的按钮。

- 地址栏按浏览器的规则解读：只写域名（如 `example.com`）时以 `https://` 打开，输入框里回车即打开。不是 http 或 https 的地址会被拒绝。
- 画面就是页面本身。**点击画面即可操作它**：单击、双击、右键、拖动和滚轮都会传给那个页面，键盘输入也一样，按 Tab、回车、方向键都可用。
- **用输入法打字也可以**：字母、数字、符号、回车、Tab 和方向键按键盘传过去，中文这类由输入法组合出来的字整段送过去。画面上盖着一个看不见的输入框，就是输入法组合的落点。
- 画面上方一行显示当前页面的标题、地址和它是否还在加载，右侧是浏览器当前绘制页面的尺寸。
- 页面按这个页面的框大小重绘。把窗口拉窄或拉宽，服务器上的页面会跟着变宽变窄——就是你在这块区域里看到的那个尺寸，所以不用放大镜。
- 画面中断（比如浏览器被停掉、或服务器重启了服务）时，中间会出现一句话和一个**刷新**按钮，点它重新连上。

浏览器在你关掉这个页面后**继续运行**：它不是这个页面的附属物，别人打开这个页面看到的也是它。要真正放掉它，按工具栏最右边的**停止浏览器**。

## 登录状态留在服务器上

浏览器自己的配置文件放在服务器的数据根目录（`<数据根>/browser-profile`），因此你在里面登录过的站点，在服务器重启、甚至升级之后仍然登录着——换台机器打开这个页面，看到的还是同一个已登录的浏览器。

这个目录是整机共用的。谁用这个服务器浏览器，用的就是同一份登录状态。

## 关闭或另指一个浏览器

服务器上没有 Chromium 或 Chrome 时，这个页面会直接说明，而不是给一个空框。想让服务器别拉浏览器起来，设 `ADELIE_SERVER_BROWSER=off`；浏览器装在别处或用的是别的名字时，用 `ADELIE_SERVER_BROWSER_BIN` 点名它的可执行文件。两个变量见[配置](/configuration#环境变量)。

浏览器在这个数据根目录里第一次启动时会新建自己的配置目录；数据根所在的磁盘因此需要能写。

## 服务端接口

页面背后的路由组是 `/api/server-browser`，与页面一样仅管理员可用：

- `GET /api/server-browser` — 现在的状态：这台服务器能不能显示浏览器、浏览器是否在运行、当前页面的地址、标题和绘制尺寸。
- `POST /api/server-browser/start`、`/stop` — 启动或停止浏览器。
- `POST /api/server-browser/navigate`，请求体 `{ url }`；`/back`、`/forward`、`/reload`（可选 `{ hard }`）。
- `POST /api/server-browser/resize`，请求体 `{ width, height }`（会被收敛到 320×240 与 1920×1200 之间）。
- `POST /api/server-browser/input`，请求体 `{ events: [...] }`，一次一批输入事件，顺序执行。
- `GET /api/server-browser/frames` — 画面本身，一条 `multipart/x-mixed-replace` 的 MJPEG 流，交给一个 `<img>` 就能播放；落后时丢帧而不是排队。

服务器上没有浏览器、或它被关掉时，读状态会得到 `available: false` 和一句原因——它不会被报成故障。
